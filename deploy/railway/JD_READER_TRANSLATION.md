# HHBA 个人即时中文岗位阅读（2026-10-18）

## 用户可见的问题及修复

此前详情页将完整中文 JD 与公共全文转载授权绑定：没有权利登记时，即使官方英文 JD 存在，中文页也只能显示“无法展示”提示。

现有两条相互独立的通路：

1. **公开保存的完整 JD 及译文**：继续受已有合法权利证据/审核控制；禁止将第三方全文悄悄转入共享职位搜索库。
2. **用户当前岗位的即时辅助翻译**：只在真实、仍被官方公开 ATS 板列出的岗位，且原始 URL/岗位 ID/标题验证一致时，通过同源 POST `/api/jobs/:jobId/translate-part` 分段获取中文。这些译文仅返回当前请求，Railway SQLite 不持久化全文；浏览器 sessionStorage 可按官方 JD SHA256 缓存本次阅读结果。

译文来自 Railway **私有 LibreTranslate 英中模型**，不需要 DeepSeek 或用户的 API Key。浏览器默认选中文，逐段显示进度，保留 English 原文、完整英文备用详情和失败重试入口。关键数字不能自动对应时，在对应中文段落后附原文以便核实。该译文仅供求职者辅助理解，并非企业官方中文 JD；正式大规模全文翻译公开发布仍需要独立评估来源使用条款和许可。

限制/注意：这是单独运行的 Railway 公测 Function，**不是** GitHub 正式 React 网站部署。每次更新需要通过 Railway 更新 Function 完整源码。上线不能只看 deploy=SUCCESS：要验真实招聘板、站内 GET、同源 POST 第一段以及最后一个分段能否成功返回。首批 Ashby Airwallex 中文阅读的真实 API 测试结果将反映在私有 Railway 部署日志中，不把 JD 原文写入日志。

## 接口保护

- POST 只接受固定域名的同源浏览器请求，固定职位 ID + 分段序号 + 原文 SHA256；不能提交任意网页、URL、模型参数或者任意待翻译的文本。
- 每次重新读取官方 ATS 岗位并核对岗位身份和版本；若变化返回 HTTP 409。
- 限制同步翻译数、每小时请求上限、正文最大字符数、最多 80 个片段。
- 机器译文绝不等价于准确的人工审核，涉及薪资、学历、签证、年限仍需核对英文。
