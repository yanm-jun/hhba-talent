# HHBA 智能网申助手 · 国内优先的独立开发预览版

**当前阶段：可在 Chrome / Edge 开发者模式安装的本地功能版（V0.2），尚未经过真实企业招聘官网的兼容性验收，也未发布浏览器扩展商店。**

本目录为 HHBA 独立实现，不包含其他项目的直接复制代码；参考了国内招聘表单相关开源项目的产品思路，并保留各第三方项目的独立许可证要求。

## 立即试用

1. 下载本目录，保持 manifest.json、popup.html、popup.css、popup.js、core.mjs、content.js 在同一目录。
2. Chrome 地址栏打开 chrome://extensions 或 Edge 打开 edge://extensions。
3. 开启开发者模式，选择「加载已解压的扩展程序」，选择本目录。
4. 点击扩展，进入「我的求职档案」，手动录入并保存资料，或导入从 HHBA 网站导出的 JSON 档案。
5. 打开一个具有标准 HTML input/textarea/select 的**真实**招聘申请网页，在扩展点击「识别当前表单」。
6. 查看每项建议、取消不想填的勾选，然后点击「确认并填写」。
7. 检查回读结果。可以在页面没有进一步改变时使用「撤销本次填写」。
8. 在官网**亲自**处理验证码、声明、附件和最终提交。

## 已实现、待实现（禁止混淆）

已实现：
- 通过 activeTab + scripting 按用户操作临时识别活动标签页标准输入、文本框和原生 select。
- 本机保存 HHBA 结构化求职档案；JSON 导入、导出、编辑和清除。
- 中文姓名、电话、邮箱、院校、专业、学历、学位、入学毕业、城市等严格规则识别。
- 对精准字段提出建议，用户确认后写入网页，发送 input/change 并回读核验。
- 不覆盖已有值；敏感/声明项跳过；可撤销仍未发生其他修改的写入。
- 无远程网络请求，无服务器 API Key，零外部脚本。

暂未实现 / 未验收：
- PDF、DOCX 的完整结构化解析；当前仅支持手动录入或确认后的 JSON 档案。
- 真正安全的 HHBA 云端登录同步及受保护的 DeepSeek 代理。
- 跨域 iframe、Ant Design/Element UI 复杂弹层、Shadow DOM、添加多段经历、自动跨页面续填。
- 北森、Moka、飞书招聘、牛客等真实系统端到端兼容性（需合规测试账户和真实样本）。
- Chrome Web Store 发布、企业大规模部署、生产级渗透/隐私审计。

## 安全边界

- 仅在用户点击扫描或填写时申请当前活动标签页权限。
- 扩展不会自动上传文件、点击提交、破解验证码或读取第三方账号密码。
- 不要求访问全部网站的 host_permissions；不使用招聘网页中的脚本执行用户输入。
- 本地存储 chrome.storage.local 不是加密保险箱，共享设备上请勿保存不必要的敏感资料。
- 识别和回填不会向 HHBA 或第三方发送求职档案，只有用户亲自使用官网提交时，网页会接收所填写的内容。
- 即便显示「已填写」，也只是该字段的即时回读核验，不能代表企业已收到申请。

## 运行规则测试

在本目录下执行：node --test tests/core.test.mjs

后续要增加国内 ATS 专用适配器时，先收集**脱敏**且授权的真实表单样本，验证识别与回填，然后再开放兼容声明。

## V0.2 产品及安全改进（独立开发）
- 单一 HHBA 智能网申服务定位；目标价 ¥0.30/完整申请任务。**当前仅内测，不收费，尚无真实支付或 AI 计费**。
- 扫描结果不传输网页内已有字段的原始内容，仅返回“已填写”状态，降低身份证、联系信息意外进入扩展界面的风险。
- 真实填写失败后回滚当前字段；多次填写的撤销记录不再在新一轮执行前直接清空。
- 字段列表增加网页定位操作，方便用户处理未识别字段。
- 不开放用户自行配置 API Key 的商业模式。后续平台 DeepSeek 密钥应当只存服务端。

- 在支持 Chrome / Edge Side Panel 的浏览器上，可从弹窗主动切换到侧边栏；不支持时回退普通弹窗。字段识别仍需用户主动点击。
