# HHBA 智能网申助手 · 国内优先的独立开发预览版

**当前阶段：可在 Chrome / Edge 开发者模式安装的本地功能版（V0.5），尚未经过真实企业招聘官网的兼容性验收，也未发布浏览器扩展商店。**

本目录为 HHBA 独立实现，不包含其他项目的直接复制代码；参考了国内招聘表单相关开源项目的产品思路，并保留各第三方项目的独立许可证要求。

## 立即试用

1. 下载本目录，保持 manifest.json、popup.html、popup.css、popup.js、core.mjs、content.js 在同一目录。
2. Chrome 地址栏打开 chrome://extensions 或 Edge 打开 edge://extensions。
3. 开启开发者模式，选择「加载已解压的扩展程序」，选择本目录。
4. 点击扩展，进入「我的求职档案」，手动录入并保存资料，或导入从 HHBA 网站导出的 JSON 档案。
5. 打开一个具有标准 HTML input/textarea/select 的**真实**招聘申请网页，在扩展点击「识别当前表单」。
6. 查看每项建议、取消不想填的勾选，然后点击「确认并填写」。
7. 检查回读结果。可以在页面没有进一步改变时使用「撤销本次填写」。
8. 在官网**亲自**处理验证码、声明、附件和最终提交。

## 已实现、待实现（禁止混淆）

已实现：
- 通过 activeTab + scripting 按用户操作临时识别活动标签页标准输入、文本框和原生 select。
- 本机保存 HHBA 结构化求职档案；JSON 导入、导出、编辑和清除。
- 中文姓名、电话、邮箱、院校、专业、学历、学位、入学毕业、城市等严格规则识别。
- 对精准字段提出建议，用户确认后写入网页，发送 input/change 并回读核验。
- 不覆盖已有值；敏感/声明项跳过；可撤销仍未发生其他修改的写入。
- 无远程网络请求，无服务器 API Key，零外部脚本。

暂未实现 / 未验收：
- PDF、DOCX 的无人工核对、全自动结构化解析：目前并不支持。网站端已开发文字型 PDF/DOCX 本地文字提取建议，需用户逐项核对后以一次性授权方式同步；扫描版 PDF 暂不支持 OCR。
- 真正安全的 HHBA 云端登录同步及受保护的 DeepSeek 代理。
- 跨域 iframe、Ant Design/Element UI 复杂弹层、Shadow DOM、添加多段经历、自动跨页面续填。
- 北森、Moka、飞书招聘、牛客等真实系统端到端兼容性（需合规测试账户和真实样本）。
- Chrome Web Store 发布、企业大规模部署、生产级渗透/隐私审计。

## 安全边界

- 仅在用户点击扫描或填写时申请当前活动标签页权限。
- 扩展不会自动上传文件、点击提交、破解验证码或读取第三方账号密码。
- 不要求访问全部网站的 host_permissions；不使用招聘网页中的脚本执行用户输入。
- 本地存储 chrome.storage.local 不是加密保险箱，共享设备上请勿保存不必要的敏感资料。
- 识别和回填不会向 HHBA 或第三方发送求职档案，只有用户亲自使用官网提交时，网页会接收所填写的内容。
- 即便显示「已填写」，也只是该字段的即时回读核验，不能代表企业已收到申请。

## V0.5 产品及安全改进（独立开发）
- 单一 HHBA 智能网申服务定位；目标价 ¥0.30/完整申请任务。**当前仅内测，不收费，尚无真实支付或 AI 计费**。
- 扫描结果不传输网页内已有字段的原始内容，仅返回“已填写”状态，降低身份证、联系信息意外进入扩展界面的风险。
- 真实填写失败后回滚当前字段；多次填写的撤销记录不再在新一轮执行前直接清空。
- 字段列表增加网页定位操作，方便用户处理未识别字段。
- 不开放用户自行配置 API Key 的商业模式。后续平台 DeepSeek 密钥应当只存服务端。

- 在支持 Chrome / Edge Side Panel 的浏览器上，可从弹窗主动切换到侧边栏；不支持时回退普通弹窗。字段识别仍需用户主动点击。

## V0.5 一键预填（仍为本地内测）
- 用户点击「一键预填安全字段」时才在当前标签页执行扫描、规则匹配、填写与回读。
- 仅对空白、非敏感且已从真实档案准确匹配的普通字段操作；其余字段保持原状。
- 可以先预览方案、手动选择项目并撤销；不会提交申请、上传附件或读取验证码。
- 目前不连接云端 AI、付费系统或账户次数；没有安全配对之前绝不从浏览器扩展读取网站登录凭据。
- 页面上的商业收费计划不是此版本已经启用收费的声明。

## V0.5 受限的浏览器账号连接（默认关闭）
- 在网站登录后生成 12 位一次性连接码；5 分钟有效、仅可兑换一次。插件输入连接码并主动授权访问 https://hhba.work。
- 服务端允许的扩展 ID 固定在 Cloudflare 环境变量中，其他扩展来源不能领取会话；没有配对密钥或标志时配对功能完全关闭。
- 兑换的独立插件令牌最长 12 小时有效，仅可读取用户自己的网申次数。令牌只存浏览器扩展 chrome.storage.session，不读取网站登录 token，不访问购买、退款和扣费接口。
- 用户可以在网站撤销所有插件会话，或在插件端断开本地连接。请在共享电脑上主动退出。
- 仅用于合成 ATS-like 页面测试的 Ant/Element/Arco/Semi 类名检测，不声明真实企业系统已完成兼容性验收。
- 动态 select / combobox 会被明确标注为需人工处理，绝不直接向其底层输入框写值。
- 账号连接、真实网申、AI 服务及按次扣费当前均未开放正式生产环境。

## V0.5 AI 字段辅助识别（安全预联调）
- 新增「AI 分析未识别字段（需已连接账号）」：只对本地规则没有确定映射的低风险字段分析。
- **每次使用均需用户主动勾选同意**。发送给 HHBA 后端/外部模型的只有非敏感网页字段标签、字段类型以及本地档案中存在的资料字段名称（例如 fullName、school），不发送姓名、手机号、邮箱值或完整简历。
- AI 仅返回可信的字段到资料键的对应关系，不返回、不生成个人信息值。插件在本地从实际档案取值，应用原有字段限制，建议全部默认未勾选，用户逐项核对后再确认填写。
- 插件只允许经过专门配对的短期凭证调用 AI 字段映射，最多每小时 3 次；页面字段和模型建议不进入数据库持久化。
- 需要正式外部服务商隐私告知获批，以及 HHBA_APPLY_AI_ENABLED、HHBA_AI_DISCLOSURE_APPROVED、HHBA_APPLY_EXTENSION_AI_ENABLED 三个开关和服务端密钥后才能请求外部模型；当前默认关闭、没有密钥、不计费。
- 用户界面只呈现 HHBA AI 服务名称；正式隐私政策需如实披露底层服务提供商。
- V0.5 不保证对真实北森、Moka、飞书招聘的全部兼容，不自动投递、不自动扣次数。

## P0 受限的「现有简历 → 本地结构化档案」同步（独立待验收 PR #273）
- 网站「一键网申」新增私有简历选择器：DOCX 在当前用户浏览器本地解压与提出保守字段建议；所有字段均允许用户修正。文字型 PDF 使用 Mozilla PDF.js 在当前浏览器本地提取可复制文字；扫描版 PDF 未提供 OCR，但可不经 JSON、在网页中手动确认字段。
- 用户在网站勾选「真实信息已核对」与「本次传输授权」之后，服务端用独立 Cloudflare Secret 下的 AES-256-GCM 暂存结构化字段，五分钟有效、同一账号插件仅可领取一次。
- 插件「连接账户」提供独立复选框与「领取一次性同步资料」按钮，若本地已有资料先明确提示覆盖，再本地保存；不会传输原始简历、不调用 DeepSeek、不扣除次数、不自动提交网申。
- 需要 Preview D1 `0014_apply_profile_sync.sql` 与 `HHBA_APPLY_PROFILE_TRANSFER_KEY` 的独立加密密钥；未配置则拒绝操作，正式站默认仍未上线。
- 为保护隐私，暂存密文有有效期与主动撤销渠道；过期密文的**定期物理清理**尚未实现，正式上线前必须配置清理任务与明确保留周期。
