# HHBA 汇方职场：专业优先招聘资源图书馆 V1

状态：**Preview only / Draft PR #332**。`main` / `hhba.work` 未获准上线。2026-11-11。

## 分类层次与唯一性

- **用户的专业（major）**是导航入口；**岗位方向（role family）**决定关键词；**行业馆（hall）**用于缩小企业业务搜索范围；**企业官方招聘来源（source）**是验证外部网址的唯一记录。
- 企业的集团主体只建立一份档案。`hhba_reviewed_recruitment_sources.id` 是来源唯一标识；一家企业可以加入一个 PRIMARY 行业馆和多个 SECONDARY 行业馆，但不得在多个馆复制招聘官网记录。
- 小米：主营消费电子馆，另关联汽车馆、互联网馆。潜在财务、法务、品牌、设计、研发岗位**属于业务搜索可能性，绝非真实在招岗位**。
- 专业是优先路线，绝不是岗位硬门槛；实际学历、技能、经验、城市要求必须以 DeepSeek 检索后的**单个官方职位详情**为准。即使机械专业找软件或会计专业找汽车企业运营，也不得一刀切禁止。
- 15 个行业总馆是可扩展的结构定义。**目前仅汽车馆是已建设细分区域、页面和可验收的试点**；其他馆只存在分类结构，不应在 UI 声称已经完整开发。

## 规范化数据库

1. `0024_major_industry_library_v1.sql`：行业馆、专业组、首批专业、岗位方向、关联路径（2026 本科专业目录精选条目，不是全国专业全量）。
2. `0025_major_industry_library_employers_v1.sql`：175 家已核验企业的主营馆与跨馆归属；汽车馆 29 家；小米 13 类示例业务岗位方向。
3. `0026_major_specific_automotive_paths_v1.sql`：49 个具体专业、175 条专业直达/跨技能岗位路线；会计优先财务、机械优先研发制造；修复汽车材料供应商未分区问题。
4. `0027_library_classification_ingest_guard_v1.sql`：新招聘来源必须先为 PENDING、先归主营馆，再升 VERIFIED；无主营馆直接标记 VERIFIED 会被数据库触发器拒绝。审计视图 `hhba_library_unclassified_verified` 应始终为 0。

旧 `industry_tags_json / business_tags_json` 保留作历史证据和 DeepSeek 参考，不再作为规范行业馆的唯一来源。

## 今后每次只开发一个馆

每个馆按固定验收步骤交付：
1. 明确主营范围及不包括的业务，建立细分区域；
2. 优先使用教育部专业目录建立专业代码→岗位方向关系；跨专业须依据技能、项目、意向岗位解释；
3. 审核该馆企业的集团官网主体与子公司、官方招聘入口，不使用企业未授权的私有 API；
4. 新企业先登记为 `PENDING`，给出至少一个 PRIMARY 馆，需要时添加 SECONDARY 馆，再根据核验证据升 `VERIFIED`。不能混合不同行业盲目做 50 家；
5. 一家企业可以跨馆；**一个企业身份只保留一份**，具体岗位保留实际用人单位；
6. DeepSeek 优先依据简历专业、技能、岗位方向及行业馆搜索官方来源；不足时扩大官方站外检索，必须验证职位级 URL、工作地点、中国大陆范围及岗位有效性；
7. 页面只展示真实已核验招聘**入口**，不可将整个公司招聘站冒充“当前在招具体岗位”；明确说明数据范围；
8. 检查移动端、URL 安全、数据库独立 Preview、合同测试、构建测试，经过验收再考虑部署正式站。

## 汽车馆样板

前端 Preview：/career-library/automotive  
Preview API：/api/career-library/automotive?major=080202（机械），?major=120203K（会计）。
- 返回专业→候选岗位方向；后者通过参数化 D1 查询获得 **汽车馆已核验企业官网招聘入口**；不替代 DeepSeek 对实时具体岗位的核验。
- 对页面出站的官方招聘链接继续使用全站统一的候选人登录保护。
- 后端查询在非 `HHBA_AUTH_ROLLOUT=preview` 环境返回 404。
- DeepSeek 白名单会附带 `primary_hall / additional_halls` 元数据，让模型基于专业与经历选优先行业馆，**不在本地对职位打分或编造职位**。缺少分类迁移时保留旧白名单，不丢弃来源。

## 样板验收关键指标

- 175 家企业：175 个主营馆、245 个行业关联、0 个缺失主营馆；

- 49 个精细专业路径、175 条专业路线；

- 小米一份企业身份，汽车馆作为 SECONDARY 且会计部门可被搜索；
- 白名单 175/175 通过官方来源规则；
- 不把已核验企业来源等同于实时招聘岗位；
- `hhba_library_unclassified_verified`=0，非法“未分类直接 VERIFIED”插入必须被拒绝；
- 仅在 Preview 和 Draft PR 审核，未动正式站。
