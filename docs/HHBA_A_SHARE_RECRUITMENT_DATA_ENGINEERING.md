# A 股官方招聘数据工程（首轮实测）

日期：2026-10-15。当前只完成官方交易所入口的可访问性和快照采集框架，未宣称完成全国公司或职位采集。

## 实测证据

命令：`apps/api/.venv/Scripts/python.exe -m hhba_data_pipeline.run --scope exchanges --dry-run`。

SSE、SZSE、BSE 官方页面均返回 HTTP 200，分别保存了 HTML 快照及 SHA-256。当前 HTML 是前端/查询壳页面，通用表格提取识别到 0 条公司；因此公司数和职位数仍为 0，不能把页面访问成功当作名录覆盖。下一步需在官方公开页面允许的范围内实现其公开数据请求适配器，并逐家公司记录状态。

已建立 PostgreSQL Alembic 增量迁移，包含上市公司、招聘主体、来源、职位、版本、技能、抓取运行、错误、原始文档元数据和逐公司状态表。原始文档默认 metadata-only，不保存未确认许可的全文。

## 合规边界

不绕过登录、验证码、访问控制或 robots；不使用转载招聘网站作为权威事实；不推断薪资、学历、状态或人数。访问失败、来源未确认和招聘为空必须作为显式状态保存。
