# Phase 3A.1 求职端字段与预览

能力核对页新增可选分组“让企业更容易了解你的能力”：所属行业、所在地区、可接受服务地区、工作年限、合作方式。字段经 `api.saveProfile()` 写入既有档案 JSON；保存会将档案重新置为草稿，须按既有流程再次确认才可进入企业投影。

授权页调用 `api.enterpriseProfilePreview()`，显示由服务端生成的企业展示预览，不由前端猜测字段权限。浏览器实际验收（合成用户）确认：保存的行业“新能源汽车”、地区“山东青岛”、服务地区“山东、全国”、年限 5、合作方式“全职、项目合作”在确认后的预览中显示。

前端开发代理默认改为 `127.0.0.1:8003`，可由 `VITE_API_PROXY_TARGET` 覆盖，修复了本地 Vite 与实际 API 端口不一致导致的注册失败。
