# 初始技术与安全风险

| 风险 | 证据 | 影响 | 缓解措施 |
|---|---|---|---|
| Docker AF_UNIX socket 复发 | Windows build 26200 与旧 Docker 4.71.0 曾留下不可删除的 AF_UNIX reparse-point | Docker daemon 无法启动 | 已隔离两个旧临时运行目录并升级 Docker Desktop 到 4.95.0；保留隔离目录，未重置数据；若复发，先停止 Docker/WSL，再按审计目录级隔离流程处理 |
| 系统 Python 3.12 损坏 | 3.12 注册项指向缺失目录；官方修复安装/卸载被 Windows Installer 1618/1601 阻断 | 系统 PATH 中 Python 不可靠 | HHBA 使用项目内 `.tooling/python312` 与 `.venv`，不受此问题阻断；后续可单独修复 Windows Installer |
| Docling 资源峰值 | 约 16 GiB RAM，模型/复杂 PDF 可能有较大峰值 | 解析时影响本机响应和磁盘 | 延后按需安装；使用小型非敏感样本基准；不预下载模型 |
| 简历隐私与 Agent 数据外泄 | 产品处理个人经历、能力、联系申请 | 高隐私/合规风险 | V0.1 前定义显式授权、字段级可见性、审计日志、数据保留与撤回机制 |
| 搜索权限绕过 | 向量/全文索引容易脱离访问控制 | 未授权资料泄露 | 权限过滤作为查询 API 的不可绕过条件；不直接暴露原始索引 |
| 第三方许可证误用 | Meilisearch 混合 MIT/BUSL；OpenCATS 混合许可 | 商业化与再分发风险 | 当前仅参考；真正引入前逐版本、逐文件和法务复核 |
| 上游 API 过期 | MCP SDK 当前为 v2.3.0 | 按 v1 示例实现将产生重工/安全问题 | 只参考 v2 官方文档与锁定版本 |
| 密钥泄露 | API/数据库配置将在本地存在 | 凭据进入 Git/日志 | `.env` 忽略、仅保留 `.env.example`、不在测试日志输出值 |
