HHBA 海外招聘市场工作方式（前端）

* 对 `ATS_OFFICIAL_METADATA`：列表仅展示企业/岗位名称/地区/招聘类别/远程状态/来源时间。直接点击标题或“企业官方岗位详情”会打开对应官方原始职位页，以查看完整 JD 或申请；HHBA 不显示未经授权的长篇 JD，也不自动投递。
* 数据引擎必须提供 `marketplace_status: ATS_METADATA_SOURCE_REVIEWED`、官方 HTTPS 详情链接，并已完成公司招聘板身份和元数据权限审核；前端校验失败立即拒绝整个错误响应，不显示虚构岗位。
* 校招/社招/实习类别来自实际可验证分类；缺失则明确显示未分类。
* 现有 `ATS_STAGING_PREVIEW` 仍仅在 localhost 内测，不会混入正式公开展示。
* 未配置真实数据库/公开版服务器时，本页面不会生成任何替代性职位。
