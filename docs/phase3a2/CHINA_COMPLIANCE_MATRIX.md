# 中国网络招聘合规矩阵（工程准备，不是法律结论）

| 主题 | 工程控制 | 运营前状态 |
| --- | --- | --- |
| 企业及经办人材料审核 | 主体、授权、审核记录与复审时间 | 待法务确认流程与材料要求 |
| 个人信息最小化 | 默认私密、独立授权、搜索投影裁剪、审计 | 待完成个人信息影响评估 |
| 网络招聘服务资质 | 平台服务独立门控 | 未清除，需确认人力资源服务/电信等适用资质 |
| 资料留存与删除 | 当前有审计基础 | 待制定法定/业务保留期限与删除响应流程 |
| 投诉举报与内容治理 | 未实现 | 未清除 |

参考：人社部《网络招聘服务管理规定》官方发布页（2021-03-01 实施）。本表不构成法律意见，公开运营前必须由中国大陆合资格法律顾问审核。
