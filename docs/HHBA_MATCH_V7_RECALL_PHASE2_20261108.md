# HHBA V7｜第二阶段岗位召回与官网核验（2026-11-08）

状态：测试分支开发、未合并 main，正式站 AI 和外部招聘搜索开关保持关闭。

## 为什么做这一阶段

2026-11-08 两轮真实 DeepSeek 测试中：软件开发者候选池 13 条但最终推荐 1 条；销售转内容运营最终 0 条。原算法把部分岗位筛得更准，但来源覆盖和检索词明显不足，不能以不相关岗位凑满十条。

## 本阶段变更

1. **明确目标优先**：存在用户明确职业意向时，官方搜索不再自动用既往履历中的另一职业分走搜索名额。例如转内容运营时，不额外搜索销售顾问。
2. **同职业同义词召回**：对内容运营、用户运营、软件开发、Python 开发、数据分析、视频剪辑等固定职位族，最多四条搜索分别使用经人工审定的同职业关键词，避免反复在不同域名检索一个短语；不把这些词当作简历能力的证明。
3. **官网抓取预算相关性优先**：允许的官网单职位详情 URL 仍要求精确匹配；若职位名称已明确跨职业，不占用有限 Fetch 名额。对于无法从搜索标题判断职位类别的结果，仅保留极少量探索名额，必须在官方详情中再次核实。
4. **已关闭职位一律排除**：企业页面明确显示“当前职位无法投递”“暂不可投递”等状态，即使网页仍有完整职责和要求，也不进入推荐池。
5. **修正英文分类与正则**：Product Lead 属于产品岗位，不能被后端研发目标当成未知职业用于推荐；英文软件工程师标题允许经过规则分类，而不是因空白正则错误被漏掉。

## 搜索范围与隐私限制

- 每次仍最多四次 Search、八次 Fetch；站外目标仅传已清洗的职位意向，不向 Search 发送简历、姓名、联系方式或原始技能文本。
- 只允许现有审定的六个企业官方招聘详情域名和固定路径；招聘页链接、内容、地点和岗位条件需经过相同严格核验。
- “官网有详情”不等于“现在仍在招聘”；只有明确关闭可确定为关闭，其他保持 `NEEDS_OFFICIAL_CONFIRMATION` 状态。
- 不扩大境外企业在境外的工作岗位；在中国大陆有工作地点的外资公司仍可按其他条件评审。

## 质量判定与待办

- 本阶段自动化证明检索查询数量和职业方向约束未破坏、安全性及原有合并排序回归通过。
- 尚未证明真实 DeepSeek 站外检索的有效召回率提升；下一次授权的真实测试应按相同固定 Search/Fetch 预算记录：官方详情获取成功数、被关闭状态排除数、符合目标与资格数、最终实际推荐数。
- 对内容运营转岗人员，不能将“希望从事”虚构成已有新媒体运营经验；保留招聘详情中明确工作经历和学历要求。
- 不宣称达到 Top3 精准率 80% 或 10/10 推荐，除非有足量真实人工标注数据。

官方招聘证据示例：美团职位 https://zhaopin.meituan.com/web/position/detail?highlightType=campus&jobUnionId=1422824064 页面仍有职责、岗位要求，但注明“当前职位无法投递”；百度社招 https://talent.baidu.com/jobs/detail/SOCIAL/fe58bce8-4479-4da8-888e-11c959eee4b3 详细规定 5 年新媒体运营经验，不能自动给仅有 3 年汽车销售经验的转型者放行。
