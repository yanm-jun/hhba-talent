# HHBA V0.1 产品需求文档

状态：Phase 1 实施中。2026-10-13 决策修订：能力档案默认私密；企业检索、公开分享、搜索引擎收录为三项独立授权；企业须经人工审核后才可使用受限搜索；联系方式只能在个人同意联系后由个人选择披露；首发中国大陆/简体中文；禁止真实简历自动外传至外部 AI；每位个人仅一个主档案。

## 1. 目标与非目标

### 目标

验证一个可控的「人才主动授权 → 企业搜索 → 联系申请 → 人才响应」闭环：个人可创建和管理能力档案；企业仅能检索被授权的字段；第三方 Agent 通过同一权限模型发起受限检索和联系申请。

### V0.1 非目标

不提供公开全网搜索、自动外发邮件/消息、付费/订阅、推荐排序黑箱、多租户 SSO、社交关系图、移动端原生应用、Meilisearch、Kubernetes 或通用 Agent 编排。AI 只做受控的建议和结构化提取，不自动发布、不自动联系。

## 2. 用户与最小场景

| 角色 | 首要任务 | V0.1 成功定义 |
|---|---|---|
| 个人用户 | 上传或录入简历，审核能力档案并设定可见范围 | 能看到、修订、撤回自己的档案；每次外部访问有迹可循 |
| 企业成员 | 用结构化条件/自然语言找授权人才，提交联系申请 | 只能看到授权字段；不能取得私人联系方式 |
| Agent 客户端 | 在已获委托范围内搜索、读取允许字段、提交申请 | 与企业端执行相同权限检查及审计 |
| 平台管理员 | 处理滥用、删除请求、审计与系统配置 | 默认不能浏览私人简历内容；受控的最小必要访问会被审计 |

## 3. 功能范围

### 个人端

1. 注册/登录、本人资料与账户删除申请。
2. JSON Resume 导入或受控文件上传（PDF/DOCX），解析任务状态可见。
3. AI 解析结果只进入草稿；用户确认后才生成能力档案。
4. 编辑经历、项目、技能、能力摘要；保留来源与版本。
5. 字段级可见性：`private`、`verified_enterprise`、`public`；搜索授权单独开关。
6. 查看、批准/拒绝/撤回联系申请；撤回授权后立即阻断后续读取。

### 企业端

1. 企业组织创建、成员加入和基础角色（owner/member）。
2. 自然语言查询先转为可审阅过滤条件；V0.1 支持技能、经验年限、地区/远程、公开状态等有限条件。
3. 搜索结果只返回策略许可的最小卡片，不返回简历原件、私人字段或联系方式。
4. 联系申请：说明用途、岗位/项目、消息；不得直接获得联系方式。
5. 查看本组织申请的状态和自身操作审计摘要。

### Agent 端

1. 每个 Agent 委托绑定到企业组织、调用方、有效期和允许工具。
2. 支持授权范围内的 `search_people`、`get_profile`、`create_contact_request`。
3. 不提供批量导出、简历下载、私人字段读取、自动批准或自动发送。

### 管理端

最小的内部队列：用户删除申请、滥用举报、联系申请风控标记、审计检索。管理操作必须写入不可变审计事件；V0.1 不制作全功能运营后台。

## 4. 核心规则

* 可搜索不等于可联系；个人必须显式启用搜索授权，联系仍需逐次申请。
* `public` 仅表示允许匿名/公开网页展示的字段；V0.1 默认不建立公共索引。
* 企业和 Agent 的返回对象必须由服务端策略裁剪，前端/MCP 不承担授权判断。
* 解析原文、模型提示词、模型输出与正式档案分层保存；正式档案只能由本人确认版本产生。
* AI 供应商为未配置状态；未获产品和合规批准，不发送真实简历或个人信息到外部模型。

## 5. V0.1 指标（仅作为验收目标）

| 指标 | 目标 |
|---|---|
| 授权外字段泄露 | 0 个自动化验收用例失败 |
| 个人完成档案确认率 | 作为观察指标，不预设商业目标 |
| 搜索到联系申请的闭环 | 测试环境中可完整走通 |
| 删除请求 | 在定义的保留/合法例外规则下可追踪、可验证 |
| 审计覆盖 | 所有认证、档案读取、搜索、联系和管理动作写入事件 |

## 6. 发布门槛

仅在 [HHBA_V0.1_ACCEPTANCE.md](HHBA_V0.1_ACCEPTANCE.md) 全部 P0 项通过，并完成 [HHBA_V0.1_RISKS.md](HHBA_V0.1_RISKS.md) 的公开运营前事项后，才可邀请真实用户。
