## 如何评价当前算法

**已证实**：真实 DeepSeek 密钥和调用通道有效；结构化简历抽取在这两个虚构样本中抽对学历、年限与技能；修复后销售经历与目标职业没有混淆；示例无大陆外位置，返回排序降序，候选官方链接核验逻辑有自动化测试。

**尚未证实**：跨行业真实用户的 Precision@3 / NDCG@10；全面职位召回率和在线开放状态；可有效为多数求职者推荐 Top10；完整登录态端到端上传交互；实际手机/窄屏弹窗视觉验收。UI 的中文转换尚须浏览器级核验。

**真实剩余问题**：候选池中符合明确目标的岗位极少；需要优先扩大面向中国大陆、有官方招聘详情、可辨别工作城市和要求的招聘覆盖度，另为职业迁移开发基于证据的可接受候选方向，不能放松学历/年限/执照/地点硬约束或制造虚构岗位。

**结论**：V7 工程回归与受限真实 API 测试通过，但真实推荐效果不足以宣布 AI 正式商用；继续保持 Draft，`main` 与正式站 AI 服务均不变。
