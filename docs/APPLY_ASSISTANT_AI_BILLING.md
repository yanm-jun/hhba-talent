# HHBA 统一智能服务：DeepSeek 与按次计费设计

当前已建立服务端独立字段映射模块及离线单元测试。尚未连接真实注册登录、DeepSeek Key、支付渠道和收费网申任务，不能宣称付费或模型功能上线。

## 用户端

- 唯一方案：HHBA 智能网申服务，预计人民币 0.30 元 / 一次完整网申任务。
- 不向用户显示 API Key、模型供应商配置或自带 Key 选项。
- 内测阶段不扣费；正式收费前必须完成支付授权、订单账本、退款和计费条款。

## DeepSeek 网关

- 文件 apps/api/apply_intelligence.py；只在服务端读取 HHBA_DEEPSEEK_API_KEY。
- 使用官方 Chat Completions 接口 https://api.deepseek.com/chat/completions 与 json_object 输出；模型名仅允许 deepseek-flash、deepseek-v4-pro。
- DeepSeek 仅接触字段标签、控件类型、有限选项文本及可用资料字段名；姓名、电话、邮箱、经历原文和网站已填入资料都不传输。
- 返回映射建议仍经白名单过滤；仅高置信度建议可返回，本地用户最终核对。
- 授权由服务端强制验证。没有可信的用户名/任务权益核验函数、没有密钥时直接拒绝，不会进行外网模型请求。

## 正式计费必需的基础设施（尚未完成）

1. HHBA 登录会话签发及 CSRF，后端自主确认用户身份，不信任浏览器提交的 user_id。
2. 国内合规的真实支付渠道，支付签名验证、订单与退款幂等和统一持久化数据库。
3. 一个用户在一个企业、一个职位、一个任务只付一次费；同一任务的多页续填和合理重试不重复扣费。
4. 服务端权益核验、每任务 DeepSeek 次数与金额预算限制、审计汇总和恶意请求限速。
5. 用户知悉资料可能涉及模型处理；在 AI 字段映射模式下尽量做到仅发送字段元信息。

不可通过前端是否显示“已支付”来判断收费成功。服务还没有接入线上，暂不启用。
