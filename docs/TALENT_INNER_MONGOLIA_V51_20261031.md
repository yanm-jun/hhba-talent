# 内蒙古自治区 12盟市 V5.1 支线（2026-10-31）

本分支 feature/talent-inner-mongolia 不影响main。12行政区：呼和浩特、包头、乌海、赤峰、通辽、鄂尔多斯、呼伦贝尔、巴彦淖尔、乌兰察布、兴安盟、锡林郭勒盟、阿拉善盟。

## 收录数量和局限
- 12个盟市：9地级市+3盟。补全后城市目录原305条+3盟=308条，293地级市不发生变化。
- 政策37条：两项2026自治区共同政策分别12地索引=24，地方专项/活动/规划13条。地方项有明确官方来源但不全是“个人现金补贴”，历史文件按历史或待核标记。
- 住房33条：24条自治区层面制度参考索引+9条有地方政府来源的住房制度/人才服务。已核实可出租单体房源数量=0；不得将制度虚报为31套真实公寓项目。
- 区级2000元困难毕业生求职、10000元首次创业必须符合身份、年度、注册时间等完整资格；各地不另领同一笔自治区补贴。
- 官方实名申请深链未全部逐项核验；办事指南按统一B/C标准，不具备A认证。
- 重点地方：包头160新政、乌海紧缺人才3年免费公寓、鄂尔多斯租补办法与2026拟补贴公示、巴彦淖尔2026新租购房办法、赤峰2026绿色通道、呼和浩特5351、阿拉善一免两减、锡林郭勒历史引进制度；分别避免期限、等级和住房互斥混用。

## 审核待办
1. 逐个核实各市盟真实人才公寓楼栋位置、租金、项目当期招租公告和剩余套数；无依据不能编造地址。
2. 逐个核实县区项目落地、各项政策个人办理直达页、当前开放窗口、联系人及电话。
3. 真正达到A完整指南需要单项目的逐项申请材料和资格分支证据、可执行步骤、独立交互验收，不能自动升级。
4. 测试城市目录308条与盟市别名、按市搜索、住房分类不混淆，生产构建成功后提供PR及独立构建包。未获授权不得合并main或覆盖Pages正式发布。
