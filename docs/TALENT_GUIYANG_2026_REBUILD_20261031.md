# HHBA 贵阳市2026人才政策重做 · 政府证据与页面验收（2026-10-31）

## 背景和真因
上个贵州分支恢复后主线贵阳市只有一条模糊的购房政策，未分别收录2026安家费、企业薪酬补助、企业活动揽才、柔性引才、筑才卡、租房补贴、人才生活津贴、2026秋季事业单位引才，导致用户虽见已开发省份，却看不到具体政策。

## 本次重做
独立9条贵阳市（贵阳贵安）正式政策，按落户引进、购房补贴、租房安居、生活补贴、就业创业分组。保留贵州其他8市州全部政策原记录不改；总数17。
独立住房4条：1个实物项目（筑巢公寓鹿冲关历史开放，总套数不是空房）、1个保租房准入轮候制度、1个租房补贴货币保障制度、1个筑梦驿站来筑求职短住服务。保留铜仁既有住房记录不改；贵州总数5。
城市首页首次进入即可看到5个类别、每条的待遇和主要资格；政策卡、统一详情、分步办理指南入口保持一致，避免只显示一条模糊的“人才住房支持”。
企业奖补严格标记受益人=用人单位，不能宣传为毕业生个人月薪；安家费分6万、4.8万、2.4万、1.2万且分两次支付；秋季引才截止2026-11-30，之后质量评级自动C，不会永远显示招聘开放。

## 重要限制
- 安家费要求首次市外引进、落户、2年及以上劳动合同、重点产业人才目录和参保条件（境外人才有例外），不是毕业即领取。
- 企业引才薪酬补贴、活动招募奖励、柔性引才补助发给企业，不能写成个人现金津贴。
- 高层次人才购房补贴和毕业生购房补贴不能自行叠加；家庭首次购房和购房日期须符合实施细则。
- 租金补贴按个人类别或毕业年限核定，租赁备案和实际满3个月等按2026团委办事指南；青年短住驿站不是长期免费公寓。
- 无当期住房库存证据，不得声称任何项目可入住或有空房。
- 所有记录为B级来源基础资料，整城A级认证没有自动提升，申报是否开放需人工核验。
