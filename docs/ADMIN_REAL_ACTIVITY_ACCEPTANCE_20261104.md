## 本分支整改
1. **账号状态触发**：真实登录令牌设置/清除时发送不携带个人信息的状态变化事件；统计组件在该事件及跨标签页登录状态变化时重新判断授权和登录状态。同一页面不跳转也能尝试账号级记录。
2. **PV 防重复**：账号登录状态变化只重新触发账号级去重记录；匿名页面 PV 仅随路由和统计授权变化触发，不因同页登录额外重复计数。
3. **真实招聘搜索事件**：统一招聘市场输入框由用户操作且输入至少 2 字后、280ms 防抖期结束时，调用现有 `job_search` 统计事件。**不会向统计系统发送输入内容或具体搜索关键词**；服务器对匿名事件按时间窗口去重，因此后台该指标代表去重后的搜索使用事件，不是逐次击键或精确提交次数。
4. **隔离集成测试**：直接调用真实 Pages Functions 身份、账号收藏、活动记录处理函数；利用仅存于测试进程内的 D1 模拟库测试会话、跨账号隔离、有效岗位、同日去重、跨功能、拒绝统计、GPC/DNT、同源限制、撤回记录、收藏独立性。绝不连接生产数据或发送真实用户手机号。

## 正式站真人授权验收步骤（仍需账户本人完成）
使用本人已注册的真实求职者账号与原管理后台 Access 管理员身份，不需要创建第二个假用户：

1. 进入 `https://hhba.work/candidate/login` 登录。
2. 进入 `https://hhba.work/candidate/account/privacy`，阅读说明后**自愿选择同意使用情况统计**。拒绝也不影响基本求职与收藏服务。
3. 在 `/candidate/jobs` 查看岗位，尝试真实输入并搜索 2 个字以上的关键词、打开真实岗位详情，在公开职位列表中收藏一个可收藏岗位。
4. 浏览 `/talent-service` 和一个城市人才政策页面，再浏览 `/companies/discover` 及具体企业档案。
5. 使用原管理员通过 Cloudflare Access 登录 `https://hhba.work/admin-preview/`，在「用户分析」查看**真实注册账号数、账号收藏、各类功能参与账号数、DAU/WAU/MAU**是否有相应变化；后台未授权、服务故障与真正的零值必须分开显示。
6. 同一账号当天再次查看岗位/政策：**各分类去重账号人数不应因重复访问而增加**。请注意匿名搜索事件量与账号级去重人数不是同一指标。
7. 在个人隐私设置中拒绝/撤回授权，验证该账号的活动表记录可被删除，而已收藏的岗位保留。撤回请求出现网络错误时，不得声称删除成功；应重试并复查。
8. 如果该账号在下一个 UTC 日期再次自愿授权使用，验证 D1 次日首次活跃回访的分组计算；D7 需至少等待 7 个 UTC 日。**这不是注册日留存**。

## 数据口径与已知边界
- **已注册**：来自真实认证 D1 中 candidate 账号；注册日分组可从 `created_at` 推算。
- **账号收藏**：来自候选人账号收藏表；不可与历史设备收藏相加。
- **岗位 / 企业 / 政策参与用户**：仅限自愿授权且具有有效登录会话的按日类别聚合。
- **岗位搜索事件**：匿名同意统计的去重搜索事件，尚不能用于推算全体真实账号搜索频率。
- **回访**：以首次观察到授权账号行为的日子为分组起点；不等于新注册留存。
- **企业收藏**：当前尚无完整账号级企业收藏能力；后台必须继续标记「尚未接入」。
- 未采集的历史行为不可补记，不要展示虚假 DAU/MAU/留存；若没有成熟的 cohort，应展示「数据不足」。
