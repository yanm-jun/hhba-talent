# HHBA V4.5 全国城市搜索 — 首次验收规范

**本轮范围：仅城市名录、检索、城市导航与没有政策时的提示。** 已确认的V4首页六区块视觉顺序、人才政策、公寓和四直辖市匹配模块均不改变。

## 行政区划数据
- 2025年县以上行政区划代码（第三方历史归档，按民政部行政区划代码整理）：https://github.com/yescallop/areacodes/blob/master/data/2025.txt
- 拼音辅助校对：https://github.com/xiangyuecn/AreaCity-JsSpider-StatsGov
- 覆盖 **4直辖市+293地级市**。排除自治州、盟、地区、县级市、特别行政区和其他非目标层级。
- 精确校验行政区划代码、拼音和省份归属，不依赖任意人工编造的城市数组。
- 27个含有地级市的省份、自治区分别支持省份筛选。
- 2025代码作为版本基准；后续行政区划变化应升级源数据并重新验证。

## 页面路由
- 首页 /talent-service : 只改城市搜索能力和“查看全部城市”的目的地，六大区块及已确认的热门城市展示不变。
- 全国城市目录 /talent-service/cities : 省份筛选、城市名称/拼音、分页，每卡进入独立城市。
- 按省份目录 /talent-service/cities/{省份} : 如山东省，显示山东16个地级市。
- 城市详情 /talent-service/city/{城市} : 297个规范入口；零资料的城市显示“资料整理中”，不展示编造政策和住房。
- 搜索例子：“临沂”、“临沂市”、“linyi”、“ly”、“山东省临沂市”、“广州博士补贴”均应识别正确目标城市。
- 仅输入“山东省”进入山东城市目录，不会被错误转成北京市的政策查询。
- 输入不在目标名单的县级市、自治州或虚假城市，不会自动创造新城。

## 数据边界
城市入口已上线 ≠ 该城市有真实已审核政策。政策/住房若未整理一律显示0条或“整理中”。匹配引擎仍只覆盖四个直辖市，不误称297城智能匹配已完成。
本轮只通过GitHub Pages静态测试；阿里云正式环境不得未经确认上线。
