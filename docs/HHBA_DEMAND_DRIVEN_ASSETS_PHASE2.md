# Demand-driven public assets — second phase

No payment dependency. The existing managed authenticated matching route may enable public assets with HHBA_V4_PUBLIC_ASSETS_ENABLED=1 after applying 0090 and 0092 to the public JD D1. Keep the old catalog collector unscheduled. Public generation is CV-free; independently confirmed vacancies with no factual excerpts can retain explicitly title-direction reference material, never official requirements. Invalid public drafts get a public-only quality repair before the existing individual fallback.

R2/D1 outbox writes are best-effort, recovered in bounded batches during actual matching only. If both stores fail, the encrypted phase checkpoint carries public-only pending records. The final delivery is not blocked by unavailable asset storage. Expired pending records are not republished as new vacancies. A closed timestamp fences older writes. Employer research stores independently read same-origin excerpts, reused as source URLs that must be read again before citation. Administrator-only metrics show cumulative indexed jobs, employer-origin research records, fresh (not guaranteed open), D1 pending count and recorded reference hits. R2/temporary checkpoint pending counts are not included, and no synthetic token saving estimates are presented. Real workload quality and latency are still to be accepted.
