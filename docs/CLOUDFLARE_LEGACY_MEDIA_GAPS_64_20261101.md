# HHBA Cloudflare 独立企业图片缺口（2026-11-01）

## 范围与方法

本报告审查当前 `main` 的 156 家秋招企业入口（`domesticAutumnScreenshot20261028.json`），依据 `src/main.tsx` 的路由优先级，排除使用独立组件或已完成 `employerProfiles` V2 的企业；对其余仍经过 `AutumnCompanyProfilePage.tsx` 的企业，执行页面相同的场景图片筛选条件。

数据包括 `domesticMediaBundle.json`、`domesticMedia200Bundle.json` 与 `domesticAutumnAiScenes.json`。本清单的缺口指**旧版企业页中无法渲染合格的两张业务/办公场景图片**，不是指企业完全没有 Logo，也不代表所有城市或企业名录无图。

- 样本：156 家企业
- 独立 V2 或专门页面：92 家（含 83 份 V2 结构化档案及原有专门页面）
- 仍走旧版通用企业页：64 家
- 其中当前没有满足模板条件的独立场景图片：**64 家**

## 处理标准

1. 每家企业核实企业标识，并补齐**两张来源独立且与该企业真实相关的图片**；不能用其他企业的办公楼/行业素材冒充，AI 图必须醒目标明非实景。
2. 对来源页、图片链接、尺寸/哈希及适用版权进行记录；仅仅可访问不代表商业转载已获许可。
3. 将完成的资料升级到统一 V2 企业四模块页面，接入搜索并核对专业筛选与岗位明细。
4. 每三家作为一批，提交独立分支和可点击预览，验证后才允许并入 `main`。
5. 与 Cloudflare 打包遗漏分开处理：Cloudflare 83 个 V2 结构化档案媒体路径检查不包含这 64 家历史内容缺口。

*本审计为源码和页面筛选规则审计，不是逐个浏览器截图验收。*
