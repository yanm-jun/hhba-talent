## 数据口径

- 参考资料源：312张彼此独立的 Wikimedia Commons 许可摄影素材，按156家企业的编号初步分配，每家2张。
- **来源性质：图库行业参考照片，不是对应企业办公楼、厂房、团队、员工或官网实景，也不是新生成的AI照片。**
- 纯文件检查：312/312 独立文件，重复文件为0。**但这一点不能证明照片内容与企业吻合。**
- 首轮粗筛：23家／36张。
- 进一步按「企业主营业务 + 场景画面」匹配后，**准许测试页面展示：11家／17张；其余295张不在网站上展示**。
- 未显示企业：145家。没有找到经过本轮匹配的图片时，页面应清楚提示待核实，而不是用无关图片代替。
- 保留原始312张研究包以备重新审核和替换；不删除原始资料。

## 主要拒绝原因

1. 毕马威等专业服务企业被分配无关政府会议旧照，不是专业服务办公环境。
2. 部分科技企业被分配宗教建筑、陈旧商铺和与技术研发无关的室内照片。
3. 多家中国银行被分配同一座美国历史银行建筑，明显无法代表国内银行。
4. 广之旅（旅游服务）被分配物流货运仓库，企业主营业务不匹配。
5. 部分储能或油气企业被分配纯光伏电站；虽同属能源大类，但不能据此表示公司实际生产场景。
6. 商标、集团、子公司和具体建筑身份未核对的图不能冒充官方照片。
7. 与已证明来源的企业照片相比，行业图库参考只能作为非实景的辅助内容，不能冠以“企业总部”“企业办公照片”等标题。

## 网站功能与安全约束

- 企业 Logo+名称链接到 HHBA 站内企业详情；不因图片更换而改变。
- 156家详情页采用一致结构：企业介绍、企业图片/行业参考、主要业务与代表产品、发展节点、岗位与招聘来源。
- 不显示创始人及核心创办团队板块。
- 需要跳转到官方招聘系统的链接仍按照原 HHBA 登录校验逻辑处理。
- 目前修改仅发布 GitHub Pages **测试站**，不影响阿里云正式环境。
- 来源许可有 CC BY／CC BY-SA／公有领域，不代表企业图片授权；每张图片须保留作者、原图、许可和修改说明。
