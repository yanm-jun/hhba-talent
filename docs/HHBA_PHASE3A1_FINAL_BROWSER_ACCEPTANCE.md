# HHBA Phase 3A.1 最终浏览器验收

日期：2026-10-14。运行地址：Web `http://127.0.0.1:3003`；API `http://127.0.0.1:8003`。所有浏览器账户、档案与需求均为合成验收数据。

## 实际通过的求职端闭环

1. 从首页双入口进入“我要找工作”，打开已有的合成简历解析记录；页面显示“简历整理完成”和“等待你核对”。
2. 进入 `/candidate/review`，实际填写展示名称、职业方向、技能、行业、地区、工作年限、合作方式和服务方向，保存后页面返回“资料已保存。修改后的档案需要再次确认”。
3. 名片页正确把修改后的档案表示为“需要重新确认 / 暂不可检索 / 未发布 / 未允许”。确认档案后，企业检索独立显示“已开启”。
4. 企业预览来自服务器投影，显示职业方向、行业/地区、年限/合作方式和技能，并明确排除原始简历、私人联系方式、解析证据和精确住址。
5. 实际开启公开分享、确认发布、刷新页面；四项状态恢复为“已确认并发布 / 企业检索已开启 / 公开分享已发布 / 搜索引擎未允许”。
6. 访问真实公开 URL，页面只显示合成展示名称、能力介绍、技能和服务方向。
7. 撤回后，前端显示“企业检索授权不会因此改变”；API 对旧 slug 实测为 `404 {"detail":"profile not found"}`。
8. 随后单独关闭企业检索授权；页面显示“未开启”，并提示认证企业无法继续通过搜索找到档案。

## 实际通过的企业端闭环

1. 打开企业端自然语言输入，填写合成人才需求并进入核对页；页面明确说明未调用外部模型。
2. 创建私密需求草稿，编辑标题为“Phase 3A.1 合成培训需求（已修改）”，保存后刷新浏览器，修改后的草稿仍在列表中。
3. 当前企业为“等待人工审核”；页面明确声明该状态只能管理私密草稿，不能使用受限人才检索。

## 限制与未覆盖项

- 内嵌浏览器新标签共享本地应用 Cookie，不能证明“全新无 Cookie 浏览器上下文”的登录/重新登录流程。
- 文件选择器未能由当前浏览器自动化接口注入本地 DOCX；上传与 Worker 解析由 API 自动化测试覆盖，不标记为本轮浏览器上传通过。
- 未在浏览器中创建企业 B 或移除成员；跨企业和移除成员隔离由 Phase 2.5 自动化用例覆盖。
- 当前自动化截图可在运行时会话中审阅，但没有可安全导出的完整 1440×900、705×357、768×1024、390×844、375×812 本地截图集合。

结论：关键个人发布/撤回与企业草稿真实浏览器闭环通过；完整浏览器矩阵未完成。
