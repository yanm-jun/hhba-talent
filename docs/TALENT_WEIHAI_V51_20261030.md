## 现有资料与整改事项

- `wh-rent-26`（威海新就业无房职工住房租赁补贴）需以2026新办法替换旧规则：威住建通字〔2026〕18号，官方说明：https://www.weihai.gov.cn/art/2026/7/29/art_51913_6528765.html ，相关主管部门解释：https://zjj.weihai.gov.cn/art/2026/10/13/art_28581_6669326.html 。新版自2026-08-28实施，市区新就业无房职工租赁补贴10元/㎡·月，单人保障30㎡，本科单人月补贴350元、研究生400元是条件示例，非无条件承诺。本人毕业年限、劳动合同、社保、住房情况必须审核。
- 威海经济技术开发区2026年人才公寓政策资格答复：https://www.weihai.gov.cn/jact/front/mailpubdetail.do?sysid=182&transactId=652975 。博士、硕士、本科分类待遇受首次到经区就业创业、学历年龄等条件限制，不能写成全市无条件享受。
- 中韩自贸区产业园青年中心：经开区金诺路西、滨海大道北。2026年3月住建局项目指南披露项目5栋1610套（间），住房每间520元/月、物业费115元/间·月；咨询电话0631-5993777。来源：https://zjj.weihai.gov.cn/art/2026/3/10/art_28584_6196625.html 。
- 文登区山伟学府保障性租赁住房：世纪大道东、文山东路北。2026年7月官方指南披露304套（294套公寓、10套两室一厅），租金不高于同类市场评估租金80%，物业费1.28元/㎡·月，联系电话0631-8457989。来源：https://zjj.weihai.gov.cn/art/2026/7/10/art_28581_6474647.html 。
- `sd-weihai-youth-2025` 为2025年青年人才补贴申报批次，截止2025-12-19；应标注历史 C 类，不得在2026年当作开放窗口。来源：https://rsj.weihai.gov.cn/art/2025/11/27/art_45565_5963966.html 。
