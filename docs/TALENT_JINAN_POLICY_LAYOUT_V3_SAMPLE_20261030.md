# HHBA 济南人才政策 V3 样板验收说明

日期：2026-10-30。

## 本轮仅做一个城市的独立设计预览
- **新样板**：/talent-service/policy-layout-preview/jinan
- **原有列表**：/talent-service/list/policies/济南 （保持不变）
- **原政策详情**：/talent-service/policy/{id} （复用，不改其他城市）
- 所有其他15个山东城市、北京天津上海重庆及全国297城市的旧版列表原样保留。
- 首页六区块、四入口、城市搜索、企业和招聘页面均未修改。
- 不部署阿里云正式环境。

## 用户要核对的设计
1. 济南原有四条政策，分为两条2026年资料和两条2024历史参考，历史政策移到下面单独分组。
2. 卡片只突出分类、状态、标题、**简短主待遇及适用限制**；大段概要、重复说明从列表隐藏，详情页保持完整。
3. 分类“全部政策／生活补贴／购房安家／交通福利／历史政策”能点击筛选。无结果应显示可恢复提示。
4. 两列桌面布局、单列移动布局。原版和新版独立链接并存，用户可以AB对比再决定是否推广。
5. 政策状态只展示“申领状态待核验”，不能将2026年来源文件直接称为已开放申请。
6. 最高100万限额仅限特定B类人才；2024年的现金和交通优惠均是历史信息；政策原文链接保留并可打开。

## 验收规则
- GitHub Pages构建和数据回归测试通过才算预览可验收。
- 只有用户确认这版样式满意后，才推广到全国其他城市。
