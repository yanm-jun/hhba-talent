# HHBA Phase 3A 检索质量记录

所有数据均为明确标注的合成资料。

| 场景 | 实测结果 |
|---|---|
| 中文同义技能“销售人员培训” | 命中已确认的“销售培训”，理由标记为扩展词命中 |
| 地区、行业、合作方式、年限组合 | 只返回全部硬条件匹配的候选人 |
| `public_share` 但无 `enterprise_search` | 不进入结果 |
| 100 个合成候选人（SQLite 单元验证） | 受限第一页搜索 0.0234 秒 |
| 1,000 个合成候选人（SQLite 单元验证） | 受限第一页搜索 0.0227 秒 |
| 1,001 个合成候选人（PostgreSQL 17 容器） | 受限第一页搜索 0.0618 秒 |

PostgreSQL 测量在本机 Docker Desktop、单请求 TestClient、同机数据库容器中完成，结果不是线上容量承诺。10,000 候选人未实测，故没有将其写为通过。

排序是确定性的：满足条件的理由数优先，随后按稳定 profile 标识排序；不返回 AI 百分比。空结果不披露未授权档案数量。
