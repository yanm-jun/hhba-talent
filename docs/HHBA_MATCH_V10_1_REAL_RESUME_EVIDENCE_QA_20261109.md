# HHBA V10.1 · 真实简历私有检查与“为什么推荐”回归报告

日期：2026-11-09；工作分支：`feature/match-v8-deepseek-dynamic-official-discovery-20261108`（PR #299，Draft）。本报告不代表正式生产上线。

## 产品目标
一键上传简历、等待分析、获得排序后的真实中国大陆岗位及有说服力的“为什么推荐”；岗位链接优先直达企业官方职位，无法验证岗位资格或招聘状态时如实标注。**不要把平台变成 ATS 流程模拟器。**

## 私有简历检查（没有把真实材料加入公开仓库）
本轮仅在本地分析此前用户提供的两份 DOCX 样本：
- 政府事务 / 政策项目方向：约 **24** 行包含具体行动的经历片段，其中约 **9** 行命中“政府事务、政策申报、政企活动”等主题。
- 区域门店 / 业务运营方向：约 **20** 行包含具体行动的经历片段，其中约 **9** 行命中“销售漏斗、门店、终端运营、经销商管理”等主题；也存在少量内容传播或产品策划的独立经历。

以上数量只是本地正则抽查、不是模型质量分数，也**不是实际岗位推荐数量**。没有把简历正文、姓名、电话、邮箱、公司专属成果、个人项目唯一数据提交到 GitHub 或 GitHub Actions。

## 本次实现
1. `resume-work-evidence.js`：从**已经脱敏的简历**获取最多 10 条逐字原文行动/业绩证据。DeepSeek 提供的候选必须被完整字符串包含校验；模型没提到时才使用本地提取兜底。拒绝伪造业绩、联系方式、身份证等个人信息或脱敏占位符。
2. `verifiedProfile` + `aiExtract`：新增 `work_evidence`；模型被要求只提取最多 8 个原文项目片段，而不是凭标题编造成果。保持学历、工作年限等既有事实确认。
3. `match-explanation.js`：先引用与岗位方向相关的**具体经历原句**（包含行动范围、参与而非主导等表述），再解释其与岗位的联系；没有对应证据就不做“已证明胜任”判断。
4. `match-ranking.js` / `resume-role-evidence.js` / `domestic-search-fetch.js`：支持政府事务、政府关系、区域运营、项目运营等真实简历方向，明确区分内容运营与区域运营，避免共用“运营”一词给出假高分；必要时保留有证据的销售→内容转型提示。
5. `match-rationale-ai.js`：最终 Top10 排好后，**只追加一次可选 DeepSeek 模型请求**，为多个岗位同时生成简短、具体的原因；只向模型提供已验证的少量经历摘录和岗位名称/已知技能，**不再次发送整份简历**。AI 对每个岗位只能引用服务器预先筛出的 0-2 条合适证据；若模型调用出错、虚构数字或夸大职位经历，完全回退到已验证的本地推荐理由。AI 绝不更改原排名、资格审核、职业地点或官方链接。
6. 旧的 6 Search / 12 Fetch 搜索预算、匿名调用审计、账户每日用量与异常循环防护保留；这是技术安全上界而不是“为了节省几分钱停止找岗位”的产品目标。

## 去标识化实战回归
`apps/web/scripts/match-v10-resume-evidence.contract.test.mjs`：
- 重放政府事务样式、区域运营样式的匿名简历事实，通过同一 `verifiedProfile → scoreCandidateFit / fuseDomesticJobRecommendations → whyThisJob` 路径核对相关职位前列、无关岗位被压制。
- 不会把“参与项目”变成“独立主导”；不把职业愿望变成已经担任的职位；假的百亿项目、手机号和邮箱不能成为推荐理由。
- Model 省略工作片段时仍可本地提取可核实的行动证据。

`apps/web/scripts/match-v10-ai-rationale.contract.test.mjs`：
- 验证单次模型调用、仅发送精简的已核查事例、模型输出引用与岗位绑定。
- 反例验证不存在的领导经历/数字、上游限流和错误 JSON 不会覆盖可靠结果。

## 验收界线
- **CI 自动化是模拟真实风格简历的回归，不是 DeepSeek 实时检索出 10 个在招岗位**。本轮使用的两份真实简历只做本地私有诊断，未上传到供应商进行真实付费端到端复现。
- 尚需以真实用户授权的预览账号执行文件上传、DeepSeek 分析、实际招聘 URL 核对、用户可读解释与新调用成本监测；在此之前不把 V10.1 标为完成商业上线。
- 继续保持 Draft PR #299，不合并 main，不修改 hhba.work 的生产 AI/付费开关。
