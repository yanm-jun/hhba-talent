# HHBA 广西壮族自治区 V5.1 独立支线（2026-10-31）

分支：`feature/talent-guangxi`；目标：14地级市；未经验收不得合并 main。

## 本次实际落地
- 沿用既有全国城市字典和统一列表、统一详情、搜索路由，不增加独立 JSX 视觉模板。
- 新增 `guangxiPolicyRecords.ts`：14城 × 2条属地检索记录（共28条）。这不是28种不同补贴，而是两项自治区政策按所在城市展开，并有城市不同的咨询线索。
- 2026“三支一扶”：中央人社部收录广西公开公告，2026-06-16报名已截止，C历史，不可作为正在报名事项。每城岗位资格及电话需按公告附件复核。
- 2026自治区新建商品房补贴：住房城乡建设部网站转载自治区活动报道，确认活动线索和云闪付活动专区；**非自治区主管厅实施原文**，财政余额、当地可申领性、活动实际截止日与完整资料清单须核实。B基础资料，不虚构申报官网链接。
- A级认证仍为0，广西无任何城市标“整城完成”。
- 已有全国搜索展示政策、住房相关政策可在安居页面按类别显示，但**还没有经充分核验的广西独立住房项目记录**，不能宣传14市人才公寓已建成。
- 专项测试和GitHub Actions分支CI已设；主线Pages只从main部署，因此该分支目前提供构建工件而非已上线独立网址。

## 缺口（必须追踪，不能隐藏）
1. 逐市搜集现行有效的市级人才引进、生活补贴、租房补贴、创业支持等**市级官方原始政策**及真实申报入口。
2. 逐市查找人才公寓/保障性租赁住房的实际项目、房源地址、房型、租金与官方当期配租公告；无资料绝不造数。
3. 按申请资格分支、真实材料、办理步骤、FAQ、联系方式、官方链接建设可审核的A级详情；指南不能机械生成套话。
4. 逐城执行PC/手机UI回归、筛选和政策搜索；创建可访问、非正式站覆盖的独立静态预览并由用户验收。
5. 广西“三支一扶”各地联系方式需以2026公告附件逐一复核，不以初步线索代替最终核定。
6. 与2026-10-31主线最新变更并行，合并前必须复核冲突及重新跑全部测试。
