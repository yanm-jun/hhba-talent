# HHBA 全国城市统一模板与质量标准 V5.0 — 2026-10-30

## 开发规则
- 唯一开发仓库：\`yanm-jun/hhba-talent\`；开发分支：\`main\`。
- GitHub Pages 只作为可点开预览；未经用户确认绝不部署阿里云正式环境。
- 所有城市使用一个 \`UnifiedPolicyList\`、一个 \`UnifiedPolicyGuide\`，并由 \`UnifiedTalentRecordDetail\` 负责其余基础政策和住房资料的统一页面。
- 济南／青岛原有政策数据独立保存，数据和视觉组件分离，避免一城一套定制界面。

## 政策等级
- **A 完整办事指南**：经官方来源核对，并且有实际申请人通道、条件、待遇、可执行流程、准备材料、FAQ、主管渠道；目前4个完整指南（济南生活补贴、青岛住房补贴、青岛免租住宿、崂山配租）。
- **B 基础资料**：已收录可追溯原文，但某些完整要素未整理，不得显示“完整指南”。
- **C 历史资料**：已结束的批次或标注历史政策，即使字段齐全也只能作参考。
- **D 来源待核验**：来源不可用、不可信或缺乏出处，不作为可申领政策推荐。
以上等级是内容整理质量，不是任何申请人的通过概率。

## 内容标准
政策页面：基本信息、待遇/对象、学历合同社保住房条件、单位/个人申报方式、分步办理、材料、审核和发放、常见问题（仅充分核实的内容）、官方平台/电话、原文附件和最后核验状态。
住房页面：项目/位置、具体公布房源和租金、资格、家庭及既有住房限制、单位及个人申请、审查、补正、排序选房、签约入住、相关费用和规则、真实电话。
没有官方证据的项目必须写「待核验」，不得为凑齐格式生成统一套话、随机电话号码、固定审核天数或实时房源。
