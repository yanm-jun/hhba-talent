# Demand-driven public job assets: phase 1

The previous unattended public catalog collector is disconnected from the Cron Worker. Keep existing daily housekeeping separate; do not schedule the old collection trigger. This phase uses existing R2 and D1. Public material generation is folded into the existing public research call, not a new unattended model call.

Apply 0090_v4_public_job_assets.sql to the public JD database before enabling HHBA_V4_PUBLIC_ASSETS_ENABLED=1. The product owner has deferred payment. Enable for ordinary managed matching only after 0092 and preview acceptance; payment is not a dependency.

Shared public reference generation uses only independent vacancy metadata, verified partial text and scoped public evidence, excluding CV, applicant-conditioned search summary and private notes. Shared material requires grounded public excerpts and material review; personalized scores and reports are always generated separately. Reuse requires a newly independently verified vacancy, exact identity and partial text, and a 24-hour TTL. Hints are not verified current openings. Official archive contents remain authoritative; closed jobs are removed from the index. Index writes are best effort; an outbox and administrator dashboard are subsequent stages. The old catalog implementation remains for regression compatibility but no longer has a scheduled entry point.
