# HHBA V0.1 验收与测试计划

状态：计划。测试只使用合成数据和明确授权的测试文件，不把演示数据描述成真实平台用户。

## P0 安全/隔离验收

| 编号 | 场景 | 预期结果 |
|---|---|---|
| SEC-01 | A 企业搜索只授权给 B 企业的档案 | A 不得到结果、计数、字段或可枚举 ID |
| SEC-02 | 企业读取 private/仅另一企业可见字段 | 统一最小披露拒绝；审计记录 denied outcome |
| SEC-03 | Agent 使用过期/撤回 delegation | 所有工具拒绝，且不得泄露资源存在性 |
| SEC-04 | 个人撤回 grant 后重复调用 REST/MCP | 立即无权；搜索投影不再返回 |
| SEC-05 | 未确认的解析草稿 | 不出现在搜索、MCP 或企业端 |
| SEC-06 | 联系申请 | 企业不能在批准前得到个人联系方式或原简历 |
| SEC-07 | IDOR/参数篡改 | 更换 profile/org/request ID 不可跨主体读取/写入 |
| SEC-08 | 审计覆盖 | 认证、搜索、读取、授权变更、联系、删除、管理动作均有事件 |
| SEC-09 | `.env`、上传原件、token | 不能被 Git 跟踪、API 日志或错误响应泄露 |

## 功能与质量验收

* 单元测试：Policy 规则、字段裁剪、状态机、解析映射、分页 cursor、幂等。
* 集成测试：FastAPI + 临时 PostgreSQL；迁移升级/回滚；RLS（若启用）与 Policy 规则一致。
* 契约测试：REST OpenAPI 与 MCP tool JSON schema；相同 actor/context 的结果等价。
* 端到端：个人确认档案 → 企业搜索 → 联系申请 → 个人批准/拒绝；每步审计可追溯。
* 负载/资源：Docling 用非敏感代表性样本测 CPU、内存、时长、失败重试；搜索用合成规模数据测延迟。
* 安全：依赖扫描、认证限流、文件 MIME/大小/恶意文件测试、OWASP API 基线、人工威胁建模。
* 备份恢复：仅测试数据库执行还原演练；验证不会恢复已撤回的授权为有效状态。
