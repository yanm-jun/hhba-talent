## Native capabilities and continuity
- Actual Gemini webSearchQueries and grounding chunks are retained; missing required grounding remains incomplete, not a successful search. Redirect landing pages are independently read and registered as leads, never accepted as verified jobs solely from a citation.
- Optional GEMINI_STREAM=1 enables native SSE, with fallback only on explicit transport rejection. GEMINI_URL_CONTEXT=1 enables native URL Context for public-only JD-source recovery, not resume payloads. Both remain off until the synthetic operator probe reports native support.
- Gemini discovery defaults to adaptive parallel research unless explicitly disabled. Workers connection scheduling limits are per request, not total AI-call limits. A below-target Gemini completion gets an independent review before final partial delivery; exact repeated no-progress work is still stopped transparently rather than billed indefinitely.
- Independent background execution requires a private Workflow Worker and Pages service binding. Do not claim it is active until deployed, bound, enabled and tested with cancellation/continuation.

Context memory now rotates candidate, evidence and unresolved pages automatically for Gemini, grows accepted pages when more records exist, and reduces page size on actual provider context rejection. Original records remain intact. Discovery records measured wave latency, and report batches adapt after partial errors. Failed verification batches preserve completed evidence and retry from the original offset. Cloudflare connection headroom and evidence-validation rules remain intentional; no claim of unlimited provider capacity.

Active session slots and opaque Workflow tickets now refresh on actual authorized execution, under the same session-slot lease as cancel/close. Abandoned records retain their ordinary expiry; signed unmanaged pointers remain short-lived. Retrying a verification phase caches independently verified JD reads by candidate revision, skips already evidence-scored completed jobs after retryable scoring failures, and retains unresolved leads. Oversized public reads automatically yield byte windows with explicit incomplete status, not fabricated full JDs. The synthetic probe additionally inspects model metadata and countTokens without uploading resumes or creating persistent remote caches; provider support and privacy/retention must be reviewed before explicit caching.

The Cloudflare Workflow per-step timeout remains 30 minutes (platform guidance); retries and durable recovery distinguish this from a total research deadline. Large independently read employer pages can now parse complete structured JD within a 16 MiB transport safety budget; larger or unsupported HTML still requires window-based evidence research and is never claimed complete by inference. Legacy rewrite V4 validation no longer rejects based on 512 blocks / 8,000 chars per block / 250,000 JD chars; request transport remains bounded at 16 MiB and legacy non-V4 safeguards remain. Large contexts require provider-accepted paging, not a claim of unlimited input.

Global Gemini ranking now runs on all eligible independently evidence-scored candidates before selecting report slots. Its output must be an exact permutation of real URLs; invalid/incomplete ranking is explicitly partial with evidence-score fallback, not silent model success. Recoverable report failures receive a separate durable review before being marked unavailable. V4 archive retains the exact independently verified public JD even without conventional headings and does not cap at 240,000 characters. Full official readers use the same bounded 16 MiB transport size. Repeated identical tools receive an explicit alternate-research opportunity; no evidence fabrication or infinite unchanged loop.

Gemini ranking uses compact IDs, incremental accepted order and insertion recovery on no progress. The ranking checkpoint is keyed to the current eligible pool and deep-report evidence; when reports change the final pool, it is re-ranked before delivery. Ranking may research public company information online, with private-data search prohibitions. If neither ordering nor insertion produces new positions, preserve partial ordering and mark incomplete rather than infinite unchanged calls. Discovery automatically rotates actual query history and exposes it via memory tools. V4 editorial decisions preserve reasons and offer alternative actions on repeated unchanged editing; both trusted .work hostnames can schedule background tasks. None of these changes verifies the live relay or enables the pending production switch.

Latest recovery changes retain unchanged candidate rank positions by URL and evidence revision, salvage syntactically complete candidate objects from truncated discovery JSON as unverified leads, and use larger static reads for JD recovery with a partial-window fallback. Stage research notes are retained in task checkpoints (not the shared JD archive or public research report), merged across parallel branches and provided as model-only context. Authorized active unfinished checkpoint records refresh under the matching lease; completed or abandoned records retain expiry. V4 legacy initial rewrite preserves full rationale and audit notes. Large windows still do not prove a complete JD; the relay capability probe is required before production Gemini activation.

V4 initial/editorial resume validation no longer rejects a proposal solely by fixed length; original-quote and numeric evidence checks remain. Missing grounding metadata is evaluated after retaining syntactically recoverable candidate leads, without promoting them to verified jobs. Parallel discovery and verification collect recovery snapshots, merge independently read JD caches and never mark incomplete candidates processed. Gemini may review alternate brand/title identity against independently read originals; cross-URL alias confirmation requires the same quoted requisition identifier and city consistency, and does not bypass employer-ownership proof. This remains a guarded implementation pending full regression and live provider acceptance.

Auxiliary discovery lanes now preserve ungrounded or incomplete candidate leads for independent verification, never fabricate grounding. V4 optimization no longer rejects a title solely by length. Rate-limit responses in document optimization preserve completed suggestions and retry pending IDs with interruptible exponential backoff honoring Retry-After when available. Reassessment uses the shared adaptive text-page research engine for both versions and the same full JD. Transport and file-format security limits remain separate from model budgets.

Large V4 PDF matching now has a consent-gated browser page rendering/OCR path, with a 64 MiB browser memory boundary and bounded per-page image size. It never splits arbitrary binary PDF chunks; a failed later page returns explicit partial text. DOCX and original-file upload retain their transport/security boundaries. Whole-file OCR stays available for small documents. Page-image relay compatibility and visual accuracy require live acceptance; no claim of unlimited file capacity.
