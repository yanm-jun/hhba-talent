> 本文件是缺项台账，不是政策完工证明。官方省级政策按州市展示，不能等同于本地政策。地方住房 **program** 与真实建筑 **project** 分开统计；轮候入库不等于当前有房。未经人工验收禁止合并 main。

## 当前清点
- 行政入口：16/16（8地级市+8自治州），另保留原全国293地级市和4直辖市。
- 政策：51 条（3类全省通用 ×16=48，以及曲靖、玉溪、临沧地方政策各1）。
- 住房：37 条（32条全省住房制度索引+3条地方制度/人才服务+曲靖2条有明确政府方位描述的实际项目）。
- 省级三类：困难毕业生一次性求职补贴、首次创业补贴、乡镇村企业基层就业一次性奖补。资格互不通用，不得叠加当普惠金额。
- 目前能从项目层面对位的房屋建筑：曲靖泽福佳园、康居瑞园；2022政府方位和历史租金、2026资格公示均有政府来源，但不承诺现房空置。
- 临沧：2026-04-14起当地官方已宣布配售型住房轮候库常态化开放登记，仍非实际可购项目。
- 可独立核实地方专项政策的城市：3/16；未核实独立专项城市：13/16。
- 可独立核实实体住房项目的城市：1/16；其他城市应按地方官方公告继续搜集，而非显示假空房。
- 完整A等级政策指南：0；未经过州/市整体完工验收。

## 必须保留的安全边界
1. 地方政策条目必须记录正式官方原文、发布日、实施地域、学历岗位社保限制、有效性、申请材料来源和真实办理入口；缺项不能自动升级A。
2. 任一住房项目须独立核对项目地址、真实批次套数、户型与租金、准入条件和官网公示。政府政策规划、2022历史租金、2026资格审核的申请人数均不能换算成2026实时房源。
3. 持续回归：`node --experimental-strip-types scripts/test-yunnan-city-v51.mjs` + `node --experimental-strip-types scripts/test-talent-city-contract-v51.mjs` + `npm run build`。
4. GitHub Actions 只验证代码和静态包，并不代表已获得独立GitHub Pages在线浏览地址。正式站/阿里云不触及。
