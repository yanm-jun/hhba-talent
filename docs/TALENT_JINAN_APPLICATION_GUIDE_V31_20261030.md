## 交互与安全
1. 单独三个申报类型选项，不能把A—D类租房无房规则机械套用硕博。
2. 六步指南每步包含为什么、具体行动、完成标志；网上入口为真正政府指定的济南人才网，而非政府首页冒充。
3. 条件和材料“辅助自查”本地复选框，仅React内存，不写入账号、localStorage，也不向政府发送申请。
4. FAQ展开折叠，支持文本搜索；15个区县电话下拉选择与tel拨号链接。
5. 不保证受理中，不承诺具体个人补贴金额，不表示用户已获政府人才认定。
