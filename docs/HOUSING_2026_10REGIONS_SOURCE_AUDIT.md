## 本轮明确禁止
- 不把2012历史办法标为2026年现行房源；政府域名 ≠ 政策仍有效。
- 不把采购、建设、拟入住公示、住房补贴资格当作当前有空房。
- 不使用第三方转载未经核验的项目或房号冒充政府一手住房。
- 只在官方住房索引列真实政府来源的制度记录；研究线索保持待核验，能被城市页面点击查看但不能算入官方住房数。

## 验收条件
1. 10城市均可在正式住房或待核验资料中查到，审计打印正式4（其中国家/历史2）、研究6。
2. 官方四条均有可追溯政府来源、具体适用对象、6步办事流程和申报渠道/房源不确定性。
3. 二手/旧文件不能由简单增加计数变成可用人才公寓；如期出现2026各市住建政府原文、受理通知、真实房源，则再逐项升级。
4. 全国337城的住房、人才政策、搜索详情与 build 回归应通过，待验收后才讨论合并 main 和 Pages。
