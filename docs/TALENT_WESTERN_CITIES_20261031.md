# 西安、贵阳、银川人才政策与住房补漏（2026-10-31）

## 贵阳贵安
- 政府来源：https://www.kaiyang.gov.cn/zwgk/zdlyxxgk/jycy_5777177/jycyzc/202509/t20250924_88646118.html
- 2026年办事指南（贵阳市团市委，2026-08-05）：https://www.gygqt.cn/detail.html?category=documentation&id=FsqpdiLAWsJmiMJTHDMgs
- 购房补贴：筑才卡A-G类1万至60万元（顶尖层次最高100万）；重点产业企业新引进、35岁以下高校毕业生博士5万、硕士3万、本专科1万。
- 租房补贴：博士/E类以上800元/月、硕士/F-G类400元/月、本科/大专200元/月；人才保障房18个月、市场化房源12个月（筑才卡最长24个月）。
- 生活津贴：重点产业企业新引进D类及以上人才，D类800元/月至A类1万元/月，最长3年。
- 筑巢公寓芦荻关：政府2026-10-09报道273套，首期开出100余套，租金790元/月起；开业数据不是2026-10-31实时库存。
