# HHBA 湖南省14市州 V5.1 逐地覆盖和缺项审计（2026-10-31）

**这是独立开发分支的审计台账，并非全省政策和具体公寓已全部收齐的证明。**

## 范围与计数

- 13个地级市 + 1个湘西土家族苗族自治州；2025行政区划代码分别通过地区索引匹配。
- 全国目录从原305个入口补入湘西自治州至306个，不改原293个地级市和四直辖市。
- 56条政策：14×3条全省通用政策按属地索引=42条，14条各地区项目/人才政策/招聘和公共就业资料。**不等于56项不同个人现金补贴。**
- 37条住房资料：28条省级一间房和青年驿站政策属地参考，湘潭5个有来源的住房项目名称，衡阳、岳阳、益阳、永州各1条地方制度。湘潭政府新闻公开了“新景未来城”“锦绣时代”“锦绣世家西苑”“湘寓·畅行居”“湘寓·知慧居”，但未核实具体可导航街道门牌和当期空房，不把名称记录误标为实时可预订项目。
- 本次37条住房均为`program`资料，**目前0条同时满足正式街道地址+实时空房+当前申报入口的可申请房源**。
- 2026年10月出台的“一间房”：**长沙、株洲、湘潭、岳阳、衡阳5市计划2026年底前实施**，其余9个市州2027年底前全面启动；政策发布时间不代表2026年10月31日已经有空房。
- 个人项目申请直达受理深链与实际可用批次尚未逐项核实；所有指南不得冒充A级完整办事认证。

## 高优先级事项
1. **长沙、株洲、湘潭、岳阳、衡阳**：取得2026“一间房”首批具体房源公告、物业门牌、运营方、实际配租期、个人资格和湘易办事项深链。
2. **湘潭**：五个报道有名的项目分别核实楼栋街道、当前空房、住房面积、押金月租、真实住建申请平台；新闻报道的5571套是全市累计筹集规模，绝不是今日剩余房源。
3. **益阳**：2025年12月住房支持政策有效到2026年底，购房补贴申请有2027年截止期；须核实不同人才类别、首购房、交易网签和材料。
4. **株洲**：2026企业柔性引才项目批次10月26日截止，只允许显示历史批次和后续评审；不得继续出现“现在报名”。
5. **郴州、邵阳、娄底、湘西及其余地区**：不能把地方2025政策、政府行业招聘新闻或省级规划等同当前个人待遇，需继续核实地方实施文件和直接申办渠道。
6. **跨分支**：此分支从`main`的305入口建立；内蒙古和黑龙江各有并行支线尚未合并，后续如要合并须重新基于最新main处理城市索引与合同测试，不得覆盖。
7. **静态发布**：Actions通过并上传静态包只表示有构建产物，不等于独立在线网址；未经用户验收确认不合并main或覆盖GitHub Pages/阿里云。
