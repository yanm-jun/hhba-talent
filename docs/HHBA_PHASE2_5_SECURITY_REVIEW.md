# Phase 2.5 安全审查

- 默认私密：简历与需求草稿均不提供匿名读取接口。
- 服务端隔离：需求 API 每次验证组织活跃成员关系，并核对路径组织 ID 与记录组织 ID。
- 会话：延续 HttpOnly、SameSite=Lax Cookie 与服务端会话撤销；客户端不存会话凭据。
- 写入：延续 CSRF 验证和审计事件；审计元数据不写密码、Cookie 或原始简历。
- 公开名片：仍要求档案确认和独立 `public_share` 授权；撤回即删除 slug，使旧链接返回 404；公开响应字段白名单不含简历和联系方式。

## 尚存风险

Docling 当前仍在 API 进程线程中运行。超时后线程无法被强制终止；这不影响本阶段合成文档测试，但不满足生产级不可信文档隔离要求。公开运营前必须改为受资源限制的独立 worker/子进程，并完成恶意 DOCX/压缩包防护审查。
