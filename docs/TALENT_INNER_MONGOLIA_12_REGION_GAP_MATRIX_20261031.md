# HHBA 内蒙古自治区 V5.1 全12盟市缺项审计（2026-10-31）
本文件是透明缺项台账，不是整城完成认证。正式 GitHub Pages 仅来自 main，本支线不触碰 main；未有独立可点击浏览器预览，不得把 Actions artifact 当在线地址。

## 数据口径
- 12个盟市：9个地级市及3个盟，新增3盟至全国索引，全国308入口；保留4直辖市、293地级市、8云南自治州。
- 政策37条：24条为两项**自治区同一政策**在12盟市的属地入口；13条为本地具体文件、招聘政策或发展规划，其中赤峰有两条。地方计划不等于个人可申领现金。
- 住房33条：24条为自治区统一住房政策方向索引，9条当地人才住房制度/人才公寓服务。**项目级经核实的完整可导航门牌、当期房源、现行租金与在线申报一体证据目前为0。**
- 全部政策办事指南仅B/C级，未把任何城市认证为A级。
- 本地就业、创业、公租房、保租房、住房补助、人才公寓各属不同制度，不叠加宣传最高金额。
- 赤峰玉龙公寓细则明确博士后、博士、特定硕士分档和资格流程；鄂尔多斯康老师2026官方报道已建成166套、历史161名教师入住，均非当期空房。

## 验收和后续专项研究门槛
1. **政策资料**：逐盟市扩充本地正式政策，而不能将统一自治区政策复制到12城后宣称所有地方政策已完成；每项应独立记录具体级别、发布部门、公布日期、生效终止期、学历职称社保住房就业限制及享受互斥。
2. **住房资料**：尽可能取得每个盟市真实项目的政府公告、楼栋街道地址、户型、租金、可用套数、运营主体、当期可申报时间及材料；不能把建设计划、历史入住率与政府宣传资料当现房。
3. **办事指南**：当前有政策分步参考，官方事项直达受理入口普遍待核；需从蒙速办、内蒙古人社或各盟市政务服务平台确认真实事项才可称“直接申请”。
4. **技术回归**：须通过 `node --experimental-strip-types scripts/test-inner-mongolia-v51.mjs`、`test-talent-cities.mjs`、`test-yunnan-city-v51.mjs`、`test-talent-city-contract-v51.mjs`、`npm run build`。
5. **上线约束**：未获用户批准不合并main、不覆盖现有Pages或阿里云。CI上传独立静态构建包，仅是可下载构建成果，不是可点击的线上预览。
