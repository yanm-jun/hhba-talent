# HHBA 企业成长模块 09｜经核验的真实改善记录（隔离预览）

**状态：开发分支。数据库/后端/API/前端可以在隔离测试环境验收；尚未接入真实企业账号、员工核验或正式生产。**

## 愿景
把 HHBA「我要招人」的员工善待和企业发展结合起来：不是发放可购买的“好雇主”头衔，而是鼓励企业持续改善真实劳动条件，允许求职者查看**有证据支持的具体变化**，并为独立评分与后续商业帮扶机制提供可审计来源。

## 09 模块组成
- `infra/migrations/20261025_employer_improvements.sql`：改善事项、证据关联、审核状态和只追加历史事件。员工身份、原始文件、工资流水均不会出现在公开表映射。
- `apps/api/improvements_domain.py`：合理的实际生效时间、客观文字、隐私审核门槛与 public/private 视图分离。
- `apps/api/improvements_store.py`：企业只能链接**本企业 verified + clean 证据**；相同证据只可对应一条改善事项。审核员不能是提交者、原证据审查者或本企业成员。
- `apps/api/improvements_routes.py`：独立账户会话与组织授权的受控提交/补充/审核/撤销、公开只读时间线。
- `apps/web/src/pages/EmployerImprovementsPage.tsx`：企业申请、公开改善时间线、独立审核后台，加入现有工作台与双评分页。

## 核心规则
1. 提交时：必须已经真实实施，填实际生效日期、客观描述和已核验的对应证据 ID；不能在仅计划实施时填未来日期。证据的存储路径与原始敏感文件不公开。
2. 独立核验：第二名审核员核对事实和生效日期，并独立进行公开文本隐私检查。必须勾选 `privacy_checked` 且编辑 40–240 字的事实摘要。文件初审人、申报人、本企业成员均不能审批。
3. 公开展示：只投影 category、批准后安全摘要、实际日期、审核日期、规则版本以及“**不宣称评分上涨**”。企业内部原始标题、未审核自述、账户身份、凭证 ID 不会对求职者公开。
4. 证据失效：即使记录早已 approved，只要所关联证据不再 verified/clean，或证据存在活跃申诉，公共查询立即隐藏，不继续显示。
5. 撤销：另一个独立审核员通过有原因的受控接口撤销公开；审核事件只追加写入，数据库触发器拒绝更改历史。
6. **评分是另一套流程**：真实改善记录不能自动修改企业信誉值/善待值；没有上一季度受保护员工数据也不能猜测改善效果；HHBA 客户帮扶仍需后续独立申请审批。
7. 当前不会伪造“评分从 65 分涨到 92 分”“员工满意度提高 40%”“订单翻倍”等不具来源的对比数字。

## 暂未完成 / 上线硬性条件
- 本 repo 的 FastAPI 主入口仍然仅有 `/healthz`，`build_improvements_router` **没有自动挂载**；需要先接入可信的 HHBA 企业账号、成员权限/经办人授权和单独的审核角色、CSRF、限流。
- 敏感证据需要已部署的私人文件存储、独立安全扫描器、正式审核规程与隐私人员培训；静态 Pages 无法存储真实改善申请。
- 正式发布需要业务层双人签批、申诉纠错流程、内容审校政策、可信审计和定期复核。当前只提供结构化一名独立审核员的首轮 approval，不将它称为最终生产发布制度。
- 数据库必须以独立权限账号、加密存储、保留/删除制度和低泄露风险日志运行；审核人员的跨企业利益冲突须由真实身份服务校验。
- `VITE_HHBA_IMPROVEMENTS_API_ENABLED=0` 直到后端真实接入。真实审核或改善发布绝不可由演示账号直接操作。
- 当前版本没有“真实改善自动重算双评分”的事件管道；此操作需另外接入评分规则、内审和审计，不自动帮扶、不推送虚构合作机会。
- 申诉 correction_required 的正式最终纠正流程仍需要持续完善；不能因为改善事项获批就自动结案。

## CI

```bash
python -m pip install -r apps/api/requirements-evidence-dev.txt
HHBA_EVIDENCE_TEST_PG_DSN='postgresql://.../isolated-db' python -m unittest discover -s apps/api/tests -v
node --test apps/web/scripts/employer-improvements.contract.test.mjs
```
真实 PostgreSQL 核验：其他公司证据无法申报、资料未经安全检查无法申报、同证据重复申报拒绝、本人/本企业/文件审核人无法批准、公开摘要与保密隔离、证据被申诉自动下架、撤销留下历史、旧招聘模块回归。Playwright 验证三个页面、移动端与禁止虚构资料。
