# HHBA 人才服务 V4.7：山东16市政策深度扩充

时间：2026-10-30；变更范围：只扩充山东省16市政策数据和政策详情阅读组件。首页六大区块、297城市目录、其他城市及阿里云生产不变。

本轮在V4.6每市第一条的基础上，新增25条不同政策，目标是每市至少2条。种类包括生活补贴、住房补贴、购房安家、就业创业、企业吸纳就业支持和贷款。

## 数据诚信说明
- 不用“最高100万元”代表所有硕士都可领，济南按人才类别、房价比例及首购条件审核
- 青岛博士和硕士安家费分别限定年龄；住房月补贴与免租金住宿保障不是同一项目
- 烟台购房补贴按实际房款30%及学历最高上限双重限定
- 山东历史政策（淄博、潍坊、德州等）要明确标注，并避免假装2026仍开放申请
- 济宁OPC社保补贴明确发给用人单位；菏泽创业担保贷款需要偿还
- 日照“先租后购”属于特定房源折扣，而不是可提现现金
- 威海新就业无房补贴须核验家庭人口、面积及学历
- 聊城2026个人社保补贴目前为媒体转述人社政策，需再次核实政府办事渠道
- 枣庄官方服务指南网页访问不稳定，需由用户在当地政府网站复核
- 新增的办事材料与步骤为“准备方向”，不是虚构政府当期完整材料清单

新增条目在apps/web/src/data/talentPolicyRecords.ts，以政策ID为唯一主键。详情页会按记录显示政策支持、限制条件、办理步骤、材料准备、发放对象、风险提示及原文链接。
