# HHBA 人才政策与人才安居数据治理

人工核验基准：2026-10-30。展示政策及项目需要政府官方网站或官方政务平台来源。

### 项目数据

- 人才政策：`apps/web/src/data/talentPolicyRecords.ts`
- 人才住房：`apps/web/src/data/talentHousingRecords.ts`
- 项目存在不代表当期正在申请，更不代表有剩余空房。公告中的套数是历史批次数据。
- 未授权或未经核实的项目实景照片一律不展示。不可用通用住宅照片代替。
- 批次结束日期可自动变为“公告批次已截止”；未写截止日期的项目只标“待核实”。

### 更新流程

1. 优先读取政府的最新配租公告，更新项目名称、地点、官方出处、文件日期、条件、租金及截止时间。
2. 在源码更新 `reviewedAt`、`HOUSING_REVIEW_DATE`，记录变更与来源。
3. 执行 `node scripts/audit-talent-service.mjs` 再进行 Vite 构建。
4. GitHub Pages 静态预览人工验收以后再考虑正式发布；不能未经批准修改阿里云。

静态一致性检查只能发现缺字段、重复、过期风险，无法自动证明外部政府网站内容没有改变；政府页面反爬或临时不可访问也不能当作政策失效。

首批覆盖6座城市，不对尚未收录的其他城市编造公寓、申请入口和补贴。
