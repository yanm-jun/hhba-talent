# HHBA V0.1 风险、合规与公开运营前清单

## 主要风险

| 风险 | 等级 | 缓解/门槛 |
|---|---|---|
| 个人简历和联系方式泄露 | P0 | 字段级策略、默认私有、服务端裁剪、加密、审计、隔离负测 |
| AI 解析错误或虚构能力 | P0 | 草稿必须本人确认；保存来源和版本；禁止自动发布 |
| Agent 批量采集/越权 | P0 | 委托、短期凭据、工具 scope、限流、查询上限、审计、异常检测 |
| 企业身份滥用/骚扰 | P0 | 企业验证策略、联系限流、举报、撤回、人工处理队列 |
| 删除权与审计保留冲突 | P0 | 法务定义保留期限、匿名化规则、可证明删除工作流 |
| 第三方模型/供应商传输 | P0 | 默认关闭；逐供应商 DPA、数据地域、训练用途、保留策略审批 |
| Docling 资源与恶意文件 | P1 | 文件隔离、大小/页数限制、worker 超时、恶意文件扫描、合成压测 |
| 语义搜索偏差与歧视 | P1 | 可解释匹配、人工复核、禁止敏感特征过滤、偏差评估 |

## 公开运营前必须单独完成

1. **隐私与法务**：适用地区识别、隐私政策、用户协议、处理依据、跨境传输、未成年人规则、数据处理协议、删除与保留政策；由合格法律顾问确认。
2. **身份与认证**：密码/OAuth、MFA 管理员策略、企业验证、会话失效、账号恢复、凭据轮换。
3. **安全工程**：独立密钥管理、生产 secrets、TLS、上传恶意文件扫描、WAF/限流、漏洞管理、渗透测试、第三方依赖/许可证复审。
4. **基础设施**：生产/测试分离、加密备份、恢复演练、监控告警、日志保留、事故响应、容量与费用预算；本地 Docker 不等于生产部署。
5. **AI 治理**：模型供应商批准清单、PII 最小化/脱敏、提示和输出保留、人工审核、失败回退、模型变更评估。
6. **运营**：举报与申诉流程、客服责任人、企业滥用处理、公开状态说明、联系频率规则、透明度报告口径。
