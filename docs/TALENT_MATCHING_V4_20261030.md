# HHBA 人才政策智能预筛模块 · V4.4

**版本目标**：北京、天津、上海、重庆的结构化政策初筛，不是政府申报系统，也不是最终资格认定。

## 用户流程
1. 首页底部保留原来的匹配入口和位置，只将按钮连接至 /talent-service/match/:city。
2. 三个基础选择（城市、学历、毕业届别）仅通过当前浏览器会话的 history state 传递，**不写入 URL、不发送给后端、不保存到账户**。重新打开新标签页时可独立填写。
3. 独立匹配页显示目标城市、学历、具体届别和就业状态。额外可选条件：困难毕业生情况、户籍、工作区县、年龄、参保年限、住房情况。支持部分填写和随时修改。
4. 将官方来源索引逐条分成：优先核对 / 需要补充条件 / 历史或已截止 / 已知条件不一致。给出解释、尚需核验的材料或条件、官方原文链接。
5. 访问政策详情页可以核对文件发布日期、适用区县、待遇、申请步骤及官方原文。
6. **不处理个人身份证、姓名、手机、学历证书、社保记录、具体家庭经济状况或其他证明文件**。

## 规则与结论
- 与真实政策冲突的条件才进入“已知条件不一致”；用户没有填写的条件一律标明“待核验”。
- 北京困难毕业生求职补贴对应六类困难群体及毕业学年，不能当作所有毕业生1000元。
- 天津2027届困难毕业生补贴对应2026-10-31申报截止日期，截止后自动进入历史类。不得把2027届与2026届混为一谈。
- 上海首次创业补贴明确限定上海户籍、毕业年限、经营满一年及参保要求。
- 重庆紧缺岗位补贴有不超过35周岁、紧缺产业岗位及连续缴满一年社保条件；高新区和指定12县优惠具有地区范围。
- 对尚未结构化的旧政策统一归“需要补充条件”，不以字符串包含“硕士”等方式假设满足资格。
- 不显示“审核通过/可领取/保证符合/实时有名额”等未经授权措辞。

## 代码
- \`src/data/talentMatchEngine.ts\`：纯函数规则引擎。
- \`src/pages/TalentMatchingPage.tsx\`：独立互动入口和解释型结果卡片。
- \`src/styles/talent-matching.css\`：独立页面视觉规则。
- \`scripts/test-talent-match.mjs\`：测试毕业届别、困难资格、户籍、区域、年龄、社保和过期批次；无需真实个人数据。
- \`scripts/audit-talent-service.mjs\`：校验首页六区块未改、官方来源与引擎路由已接入。

本轮只在 GitHub Pages 静态预览验收，禁止未经用户确认部署到阿里云正式环境。
