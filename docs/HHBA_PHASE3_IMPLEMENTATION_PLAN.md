# Phase 3 可执行实施计划

本文件是开发计划，不代表 Phase 3 已实现。

## 3A：能力数据建模与检索基础

| 任务 | 依赖 | 验收标准 | 风险 |
|---|---|---|---|
| 定义 `candidate_search_projection`、可见性、索引事件与联系申请迁移 | Phase 2 confirmed profile | 新迁移可在空 PostgreSQL 与既有 head 幂等升级；无原始简历字段 | 过度复制 PII |
| 构建确认档案→投影同步与撤销失效 | 授权/审计 | 授权撤销后的查询在同一请求边界立即无结果 | 异步索引延迟 |
| PostgreSQL FTS 与结构化过滤 | 投影 | 合成数据的中英查询、空结果、分页、解释可重复 | 中文分词质量 |
| 企业准入/搜索限流策略 | Phase 1 组织审核 | P0 未审核/暂停/跨企业用例全部拒绝 | 反枚举绕过 |

退出条件：迁移、投影、FTS、撤销同步和 P0 服务端隔离测试通过。不得在此阶段添加向量或外部模型。

## 3B：HR 搜索 Agent 与候选人展示

| 任务 | 依赖 | 验收标准 | 风险 |
|---|---|---|---|
| 本地规则条件整理 API 与确认 DTO | 3A | 未识别字段标为待确认；不伪称模型推理 | 误导性“AI”表述 |
| 极简企业搜索页 | API 契约 | 输入→确认→结果→依据，加载/空/低置信度状态完整 | 前端缓存泄露 |
| 候选结果最小字段白名单 | Policy 层 | Private/撤销字段无法从响应或开发者工具获得 | 字段扩张 |
| 检索审计与速率限制 | 3A | 限流、分页上限、审计回归通过 | 组织共享账号 |

退出条件：真实浏览器用合成档案完成搜索；所有 P0 授权、IDOR、反枚举、空结果测试通过。

## 3C：站内联系与候选人反馈

| 任务 | 依赖 | 验收标准 | 风险 |
|---|---|---|---|
| 联系申请表、状态机、去重和限频 | 3A/3B | 所有非法跃迁拒绝，重复申请受控 | 骚扰/枚举 |
| 个人端收件与接受/拒绝 | Phase 2 工作台 | 仅本人可见；接受不自动泄露联系方式 | 误操作 |
| 审计、撤销和浏览器 E2E | 状态机 | 申请→处理→刷新恢复、跨企业隔离均通过 | 历史数据保留 |

退出条件：P0 安全矩阵、前后端 E2E、审计审查与体验验收通过。

## 阻塞与决策

进入 3A 没有技术阻塞。需要产品负责人批准的决策：中文 FTS 方案、候选搜索结果最小字段白名单、联系申请有效期/限频、是否将 `mcp` 从当前运行依赖延后到 Phase 4。任何本地 embedding 模型引入均需单独审批其许可证、下载量、磁盘/RAM 和离线策略。
