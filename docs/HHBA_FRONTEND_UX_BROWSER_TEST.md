## 待重启后复验

当前 8003 运行的是未启用热重载的旧 API 进程，不能覆盖运行中进程以加载本轮新增的只读接口。重启该 HHBA API 后，必须以合成账户完成：

1. 选文件 → 登录 → 文件仍在当前 SPA 中 → 上传；
2. 任务状态刷新/重新进入后的恢复；
3. 核对、保存、生成名片、三项授权、发布、刷新、撤回及旧链接拒绝；
4. 企业输入 → 整理 → 登录 → 创建组织 → 保存 → 编辑 → 刷新/重新登录；
5. 375×812、768×1024、1440×900 的关键页布局。

该未完成浏览器复验是验收证据缺口，不得解释为已通过。
