## 最终复验（2026-10-14）

已安全重启 HHBA API（仅替换旧的 8003 HHBA 进程），并以合成账户 `ux-browser-20261014@hhba-synthetic.com` 实测：

1. 上传合成 PDF → Worker 解析完成 → 进入核对页；
2. 保存人工确认资料 → 生成名片 → 开启公开分享 → 发布；
3. 刷新后会话与撤回入口仍有效；撤回后同一旧公开链接显示“此分享链接不可用”；
4. 企业自然语言输入 → 需求整理 → 创建组织 → 保存 → 编辑 → 刷新 → 退出/重新登录后需求仍存在。

第一次上传失败的原因已定位为 API 从仓库根目录启动，使相对上传目录与 Worker 的只读挂载不一致；Worker 正确拒绝为 `PRIVATE_FILE_MISSING`。以 `apps/api` 为工作目录重新启动 API 后，第二次合成文件解析成功。不是 Docling 或权限缺陷。
