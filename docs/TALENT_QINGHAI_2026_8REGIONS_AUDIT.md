# 青海省 2026 人才政策 HHBA V5.1 · 分支交付审计（2026-11-01）

## 范围与真实性说明
青海省 8 市州：西宁、海东、海北、黄南、海南州、果洛、玉树、海西。2026年招聘宣讲、当地政府文件、住房报道和工程招标属于**不同证据等级**。
不把2025年发布但针对2026届的公告标为2026年颁布；不把招聘名额、累计住房存量或规划建设量当成个人可申领补贴、实时空房。
这是一轮实施性分支开发，不表示8州全量县区已核查完毕。所有未核实的官方办理入口、条款和材料须明确标注。

## 本阶段可核实交付数量
- 17条市州政策/公开措施记录，其中包含地方2026引才宣讲说明（实施细则未找到）、县级灵活就业补贴、政府营商人才服务、既有柔性引才实践、已结束招聘/文化专项及普惠购房补贴。
- 7条住房项目/政策或建设线索。实物公寓历史建成与招标项目不得称为2026实时空房。
- 8市州全部接入现有城市目录；海南州名称单独匹配，不误入海南省。
- 统一完整指南路由 /talent-service/policy-guide-preview/qinghai/{policy|housing}/{id}。
- 只增加数据与共享路由，不新建另一套独立页面样式，不更改贵阳或其他省份政策数据。

## 需要区分的重大风险
1. 市州安家费数值来自2026青海招聘主办方宣讲转发，不是地方财政施行细则；页面严格标「细则待核」「实际受理待核」。
2. 果洛州2026本级统一安家费与人才房政策尚无足够一手依据，不擅自编造，更不能为了数量充数；录入的两条招聘性质记录均为历史/原件仍待核。
3. 海东互助县购房补贴为2026年普惠住宅政策，非人才专属，不应误纳入专属政策金额计算。
4. 2026-11-01 同德县灵活就业社保补贴批次尚未到2026-11-27截止，而果洛2026-10-20招募已结束。
5. 2026海西人才公寓累计670套不是现时空房；玉树曲麻莱35套属于新建招标，206套属于干部住房供氧改造。
6. 来源为主办单位转发、媒体转载或招聘网站的，均不得仅因数据字段完整而显示A级认证。
7. 2026省级共通就业资金/三支一扶/校园引才为全省制度，应在后续共享政策模型单建，不复制八遍伪装市州原创项目。
8. 省市县官网发布的材料与真正在办理的事项入口不同，页面只提供已知的原始证据，不虚构申领网址。

## 2026-11-01 第二轮全面补漏：省级共享 / 地方独立 / 住房实际执行分层
用户指出“只有17政策7住房”明显偏少。再次对照2026年度省级及市县政府官方公开信息，新增：
- **11条省级共享政策**：就业困难与毕业生灵活就业社保补贴、首次创业1万元、公益岗支持、三支一扶在岗生活补助、2026省直事业单位引才博士40万元/硕士10万元/本科3万元、引进拔尖人才职称发展、配偶考核聘用、子女入学支持、文旅就业创业专项、职业培训跨地交通费（500/1000元）、职业培训生活费（30元/8课时折一天）。仅青海省数据索引中存一次，8市州页面“共享政策”区和搜索按属地引用，不复制8份。
- **9条住房正式记录**：其中2条全省通用（城镇住房困难家庭租赁补贴制度、2026引进拔尖人才省级周转住房申请机制）；地方7条：西宁市湟中区2026公租房申请公示及2026第三季度租赁补贴，海东市引进人才配售型保障住房办法（2025发布须核2026是否修订），海西州格尔木市2026新版公租房管理和货币租赁补贴、2026第11批历史申请公示、民乐苑小区现有住户年审实证。
- **政策原始分层**：第一轮17条研究线索保留，只有其中6条能过政府一手来源门禁；第一轮7条住房线索中5条政府一手。增补11条政策与9条住房均来自.gov.cn，合计目前 **17条政府来源政策（6+11）**、**14条政府来源住房（5+9）**。这31条是“整省独立去重索引数”，不是每个市州各有31条，不包含第一轮仍待核的二手来源。
- 贵德县旧《住房租赁补贴实施细则》有效期已于2021年到期，发现后**排除**出2026正式库；不是假定所有旧政策仍有效。
- 2026省级校园引才公告实际于 **2025-11-14** 发布，属于“面向2026届”，不能把原发布年份改写为2026。市州补贴金额以实际地方细则为准，省直安家费不覆盖市州事业编制岗位。
- 2026年9月格尔木第11批公租房虽当期说“房源充足”，截止9月12日；现已归档C级历史批次，不等于11月还有现房。民乐苑年审可证已入住，但不能从住户数推导可租套数。住房建设总量和实际选房持续分开。
- 西宁市湟中区2026年10月27日第三季度租赁补贴公示反映当期实际支付审查，不是普通毕业生生活补贴或新申请入口。
