# 广西、贵州省级住房政策与地方26地区缺口分离核验（2026-11-01）

> 重要：以下均为**跨地级城市/州通用参考**，**不能**在全国 `TALENT_HOUSING_RECORDS` 中复制出“12市广西地方住房政策”或“7州贵州独立人才公寓”。只有地方住建/政府直接原件、申请资格和属地项目核实后才能计当地正式索引。原有目标共四川7、广西12、贵州7=26个，独立地级/州级深度完整覆盖未达成。

## 一、广西2026高校毕业生安居补贴（自治区统一计划）

**政策依据**：广西住房城乡建设厅2026年9月推出《支持高校毕业生安居补贴公告》，《关于印发支持高校毕业生安居补贴实施方案的通知》桂建保〔2026〕5号；广西日报2026年10月1日报道（**媒体引用，不等于政府政策原始文件**）：
https://www.gxnews.com.cn/staticpages/20261001/newgx6abda183-22000092.shtml

**2026政策共性而非12市独有政策**：
- 2026-07-01至2027-01-31在广西新签国家/自治区计划内保障性租赁住房合同并实际租住，租期不少于6个月、累计实际缴租至少3个月；
- 毕业两年内全日制专科及以上（毕业证2024年及以后）；
- 基础补贴按实际已缴3个月租金总额50%核定，按人才身份、签约年限、多子女家庭可叠加，合计最高不得超过3个月租金，不代表全民全额减免；同家庭仅一人且只能领一次；
- 据2026年10月报道：自治区专项资金池1000万元，先到先得，用完即止。2027-02-28 18:00为最晚线上申报时间，但资金用尽会提前关闭；
- 通过云闪付App“广西消费券专区”申报，基础材料为身份证、本人Ⅰ类银行卡、毕业证、租赁合同、租金缴费记录及真实性承诺，叠加条件材料另附；
- 需确认实际租住房是否属于**经主管部门认定的项目清单**；普通私人租赁不能自动认作计划内保租房，申请人不能以省政策确定市区项目房源和租金。

**地级市实际执行证据分层**：
- 南宁2026-10-27住建局地方公告全文见广西新闻网（https://v.gxnews.com.cn/a/22009421），公布本市已运营保租项目附件和咨询电话0771-5705842；**附件原件、运营单位与具体门牌未验证**，仍需市局官网原公告，故为本市研究线索；
- 梧州2026-10-13市住建局公告转载提10个保租项目（https://www.sohu.com/a/1087042928_121106875），政府原文和项目附表未获得，不能报称10套在租；
- 北海、贺州等有媒体报道，不构成当前可申请的本市项目清单；
- 柳州等其他城市不能仅凭省级政策拿到“市级政策完成”的状态。

**广西省级旧制度**：2025-02广西住房城乡建设厅《广西公租房保障基本公共服务导则》政府网站存档（https://www.fcgs.gov.cn/zfxxgk/zdlyxxgk/bzxzf/bzxzfzc/P020250508644567787271.pdf）是全自治区统一底线，不是2026任何具体城市的公租房配租批次。原PDF需人工核对文件版本和后续修订。

## 二、贵州2025配售型保障住房共同办事指南（非当地独立房源）

贵州省住房城乡建设厅2025-03发布《贵州省配售型保障性住房申请指南（试行）》。省厅资料经人民网贵州频道2025-04-02报道并列出九市州的不同二维码，但原文完整版本及地方附件需再次与省厅核验：
https://gz.people.com.cn/n2/2025/0402/c361324-41184376.html

**范围与申请路径**：
- 配售型保障性住房是**产权购买**（按规定封闭管理），不是公共租赁住房、人才公寓，更不是免费租房。
- 面向符合条件工薪收入住房困难家庭和引进人才。基本限制包括本地无自有住房、重复享受政策住房的排除；当地户籍、社保和人才特殊资格要求必须按各市州正式细则分别核对。
- 可通过配售型保障性住房轮候库App、贵州政务服务网、贵人服务移动端（多彩宝、支付宝/微信）或政府窗口提出申请；这不是2026年具体项目保证开售。
- 申请、资格复核、轮候、当期项目登记、选房、签约及后续产权封闭管理须以各地公告核实。

**区分七地的独立来源不足**：
- 六盘水：2025六盘水府办发〔2025〕7号《配租配售型保障性住房管理办法（试行）》全文仅确认到第三方重刊（https://zc.51shebao.com/detail/838021），需市政府原件，未取得2026真实项目和申报批次；
- 毕节：2025毕府办发〔2025〕15号配售型办法第三方重刊（https://www.sohu.com/a/919247092_121106902），需要市政府门户原件；不能误当成当期人才公寓；
- 遵义、安顺、黔西南、黔东南、黔南：继续找市/州及县住建2026年实际受理公告，不能以人民网所列全省办理系统二维码自动认作具体当地制度。

## 三、数据验收等级

`research`：媒体/第三方原文或省级共享制度；不能关闭城市独立住房缺口。
`program`：当地县市州政府主办原始正式制度，有真实的资格、渠道、流程；仍未核实空房时不能作为项目供应。
`project`：进一步具备政府/运营单位明示的具体项目、真实地址、出租对象和价格；仍需单独确认“今日有房”。
`current_acceptance`：当前报名期官方公告/服务入口、真实可用房源经进一步确认；这是最严格状态。
