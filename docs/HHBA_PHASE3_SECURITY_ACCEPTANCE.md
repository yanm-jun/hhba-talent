# Phase 3 安全验收标准

## P0 策略测试

1. 未登录、未审核、暂停企业不能调用搜索或创建联系申请。
2. 企业 A 永远无法读取企业 B 的需求、搜索历史、联系申请或其状态。
3. 个人未确认档案、未授权企业检索档案、已撤销档案不出现在任何搜索结果、计数、分页或缓存中。
4. 修改 profile ID、contact request ID、组织 ID、分页游标均不能跨主体读取或修改。
5. 公开分享授权不替代企业检索授权；搜索引擎授权不替代任一授权。
6. 联系申请不返回原始简历、私人联系方式、source evidence、内部审计数据。
7. 授权撤销/档案删除后，立即拒绝新搜索读取；索引与向量异步清理不影响策略结果。
8. 高速重复查询、宽泛分页和联系轰炸均被限流、去重并审计。
9. 审计日志不含完整简历、完整查询自然语言、密码、Cookie、Token、联系方式。
10. Phase 1/2.6 的会话、CSRF、IDOR、组织隔离及 Worker 测试持续通过。

## 检索质量与隐私验收

- 使用明确标记为合成的中英文/中文能力档案集做召回、排序和空结果评测。
- 每个候选结果至少有一项来自已授权字段的匹配依据；无法解释时不展示结果。
- FTS/向量索引重建、撤销、恢复在事务和故障恢复测试中可重复验证。
- 企业前端不得通过隐藏按钮或缓存保留已撤销候选资料。

## 上线前非功能门槛

渗透测试、日志保留策略、速率限制存储、备份恢复演练、中国大陆个人信息合规审查、企业审核 SOP 和人工申诉流程均另行完成，不因 Phase 3 开发测试而自动通过。
