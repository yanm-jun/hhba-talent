# Phase 2.6 浏览器验收

真实隔离地址：Web `http://127.0.0.1:3001`，API `http://127.0.0.1:8001`，专用测试数据库。

已实际观察的浏览器步骤：

1. 首页双入口；
2. 合成账户注册并进入工作区；
3. 选择合成 DOCX、私密上传；
4. 任务显示 queued/processing，独立 Worker 完成解析；
5. 核对页面编辑并保存；
6. 确认档案、勾选公开分享、发布名片；
7. API 返回公开字段白名单，不含文件和联系方式。

浏览器自动化只能呈现截图，当前连接不提供受控的本地截图落盘接口，故没有伪造截图文件路径。撤回操作因刷新后 CSRF 缺失发现失败；修复已加入代码与自动化测试，但需要启动热更新后的测试实例后复验浏览器撤回。
